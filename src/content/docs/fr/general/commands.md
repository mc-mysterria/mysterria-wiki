Voici les commandes que les joueurs ordinaires peuvent utiliser sur le serveur principal. La plupart de Mysterria passe par des menus, donc une commande absente de cette liste ne marche sans doute pas pour les joueurs.

## Commandes qui n'existent pas

Il n'y a **pas** de `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` ni `/back`. Voir [Monde et sécurité](/fr/general/world-and-safety/#existe-t-il-home-spawn-ou-tpa-).

## Pour commencer

| Commande | Ce qu'elle fait |
|---|---|
| `/register <password> <password>` | Inscrire un compte hors ligne (première visite seulement) |
| `/login <password>` | Se connecter à un compte hors ligne |
| `/verify` | Lier ton compte avec le code de ton [profil sur le site](https://www.mysterria.net/en/profile) |
| `/magic` | Guide des nouveaux joueurs, avec le menu **Loot Focus** |
| `/guide` | Livre guide en jeu |
| `/faq` | Questions fréquentes |
| `/hints` | Astuces de jeu |
| `/lang` | Changer la langue des messages du plugin |

## Ton Beyonder

| Commande | Ce qu'elle fait |
|---|---|
| `/coi menu character` | L'écran de ton personnage avec ta Séquence, ton Interprétation, ta Santé, ta Spiritualité et ta Folie |
| `/coi menu abilities` | Tes capacités |
| `/coi menu native` | Passer des écrans du [Client Mod](/fr/guides/client-mod/) aux menus en coffre, et inversement |
| `/coi acting` | Les temps de recharge des méthodes d'Interprétation et ton Interprétation par source. Voir [Interprétation](/fr/magic/acting/) |
| `/bounty` (ou `/coi bounty`) | Primes d'Interprétation |
| `/ritual status` | Ton score de rituel pour la prochaine Séquence. Voir [Rituels](/fr/magic/rituals/) |
| `/ritual view <sequence>` | Tes tâches de rituel dans un menu, où tu peux demander un nouveau tirage |
| `/coi practice` | S'entraîner au mini-jeu de préparation sans rien risquer |
| `/coi tide` | La Marée quotidienne du jour. `/coi tide calendar` affiche les jours à venir. Voir [Marées quotidiennes](/fr/guides/tides/) |

Les joueurs de haute Séquence utilisent aussi `/coi usurp` ([Usurpation](/fr/magic/usurpation/)), `/coi ascend` et `/coi ascension` ([Séquence 0](/fr/magic/sequence-zero/)), ainsi que `/coi church` ([Églises](/fr/magic/churches/)).

## Argent et boutiques

| Commande | Ce qu'elle fait |
|---|---|
| `/wallet` | Ton argent. Voir [Économie](/fr/guides/economy/) |
| `/emporium` | L'[Emporium brillant](/fr/guides/emporium/) |
| `/daily` | Récompenses quotidiennes |
| `/vote` | Voter pour le serveur |
| `/battlepass` (ou `/bp`) | Le Battle Pass |
| `/calendar` | Le calendrier des récompenses |
| `/tradeall` | Vendre tous tes ingrédients à un villageois contre des [Éclats d'énergie](/fr/guides/economy/#éclats-dénergie) |
| `/oga` | L'événement des Ancres des Dieux Extérieurs et sa boutique de récompenses (`/oga rewards`) |

## Villes, groupes et chat

| Commande | Ce qu'elle fait |
|---|---|
| `/lands` (ou `/land`) | Créer et gérer une ville. Voir [Villes](/fr/guides/towns/) |
| `/nations` (ou `/nation`) | Nations |
| `/wars` | Guerres entre villes |
| `/o` | [Ordres secrets](/fr/guides/orders/). `/oc` est le chat de l'Ordre |
| `/party` | Ton groupe |
| `/msg <player> <message>` | Message privé (aussi `/pm`, `/w`) |
| `/r` (ou `/reply`) | Répondre au dernier message privé |
| `/ignore <player>` | Ne plus voir les messages d'un joueur |
| `/titles` | Choisir un titre |
| `/chatcolor` | Couleur du chat |

## Donjons et événements

| Commande | Ce qu'elle fait |
|---|---|
| `/subspace` | Chaque donjon, son entrée et tes temps de recharge. Voir [Donjons](/fr/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Groupe de donjon, vérification que tout le monde est prêt, quitter le donjon |
| `/cosmos` | [Incursions du Cosmos](/fr/guides/cosmos-incursions/), avec `/cosmos guide`, `status`, `shop`, `balance` et `leaderboard` |
| `/pvpevent join` | Rejoindre un événement Duels ou FFA pendant les inscriptions (`/pvpevent status` les affiche) |
| `/bedwars` | Bedwars |

## Autres

| Commande | Ce qu'elle fait |
|---|---|
| `/sit`, `/lay` | S'asseoir ou s'allonger |
| `/uar` | Temps restant avant le prochain redémarrage du serveur |
