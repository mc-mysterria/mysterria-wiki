These are the commands ordinary players can use on the main server. Most of Mysterria runs through menus, so a command missing from this list probably does not work for players.

## Commands that do not exist

There is **no** `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` or `/back`. See [World and Safety](/general/world-and-safety/#is-there-home-spawn-or-tpa).

## Getting started

| Command | What it does |
|---|---|
| `/register <password> <password>` | Register an offline account (first visit only) |
| `/login <password>` | Log in to an offline account |
| `/verify` | Link your account with the code from your [website profile](https://www.mysterria.net/en/profile) |
| `/magic` | Newbie guide, with the **Loot Focus** menu |
| `/guide` | In-game guide book |
| `/faq` | Common questions |
| `/hints` | Gameplay hints |
| `/lang` | Change the language of plugin messages |

## Your Beyonder

| Command | What it does |
|---|---|
| `/coi menu character` | Your character screen: Sequence, Acting, Health, Spirituality, Madness |
| `/coi menu abilities` | Your abilities |
| `/coi menu native` | Switch between the [Client Mod](/guides/client-mod/)'s screens and the chest menus |
| `/coi acting` | Acting method cooldowns and your Acting by source. See [Acting](/magic/acting/) |
| `/bounty` (or `/coi bounty`) | Acting bounties |
| `/ritual status` | Your ritual score for the next Sequence. See [Rituals](/magic/rituals/) |
| `/ritual view <sequence>` | Your ritual tasks in a menu, where you can ask for a reroll |
| `/coi practice` | Practise the brewing minigame with nothing at stake |
| `/coi tide` | Today's Daily Tide. `/coi tide calendar` shows the coming days. See [Daily Tides](/guides/tides/) |

High Sequence players also use `/coi usurp` ([Usurpation](/magic/usurpation/)), `/coi ascend` and `/coi ascension` ([Sequence 0](/magic/sequence-zero/)), and `/coi church` ([Churches](/magic/churches/)).

## Money and shops

| Command | What it does |
|---|---|
| `/wallet` | Your money. See [Economy](/guides/economy/) |
| `/emporium` | The [Brilliant Emporium](/guides/emporium/) |
| `/daily` | Daily rewards |
| `/vote` | Vote for the server |
| `/battlepass` (or `/bp`) | The Battle Pass |
| `/calendar` | The reward calendar |
| `/tradeall` | Sell all your ingredients to a villager for [Energy Shards](/guides/economy/#energy-shards) |
| `/oga` | Outer Gods Anchors event and its reward shop (`/oga rewards`) |

## Towns, groups and chat

| Command | What it does |
|---|---|
| `/lands` (or `/land`) | Create and manage a town. See [Towns](/guides/towns/) |
| `/nations` (or `/nation`) | Nations |
| `/wars` | Town wars |
| `/o` | [Secret Orders](/guides/orders/). `/oc` is Order chat |
| `/party` | Your party |
| `/msg <player> <message>` | Private message (also `/pm`, `/w`) |
| `/r` (or `/reply`) | Reply to the last private message |
| `/ignore <player>` | Stop seeing a player's messages |
| `/titles` | Choose a title |
| `/chatcolor` | Chat colour |

## Dungeons and events

| Command | What it does |
|---|---|
| `/subspace` | Every dungeon, its entrance and your cooldowns. See [Dungeons](/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Dungeon party, ready check, leave the dungeon |
| `/cosmos` | [Cosmos Incursions](/guides/cosmos-incursions/), with `/cosmos guide`, `status`, `shop`, `balance` and `leaderboard` |
| `/pvpevent join` | Join a Duels or FFA event while signups are open (`/pvpevent status` shows it) |
| `/bedwars` | Bedwars |

## Other

| Command | What it does |
|---|---|
| `/sit`, `/lay` | Sit or lie down |
