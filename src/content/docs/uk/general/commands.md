Ось команди, якими звичайні гравці можуть користуватися на головному сервері. Більша частина Mysterria працює через меню, тож команда, якої немає в цьому списку, найімовірніше не працює для гравців.

## Команди, яких немає

Команд `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` і `/back` **немає**. Дивись [Світ і безпека](/uk/general/world-and-safety/#чи-є-home-spawn-або-tpa).

## Початок

| Команда | Що робить |
|---|---|
| `/register <пароль> <пароль>` | Зареєструвати офлайн-акаунт (лише під час першого входу) |
| `/login <пароль>` | Увійти в офлайн-акаунт |
| `/verify` | Привʼязати акаунт кодом із [профілю на сайті](https://www.mysterria.net/en/profile) |
| `/magic` | Путівник новачка з меню **Loot Focus** |
| `/guide` | Книга-путівник у грі |
| `/faq` | Часті питання |
| `/hints` | Підказки до гри |
| `/lang` | Змінити мову повідомлень плагіна |

## Твій Потойбічний

| Команда | Що робить |
|---|---|
| `/coi menu character` | Екран персонажа з Послідовністю, відіграшем, здоровʼям, Духовністю й Божевіллям |
| `/coi menu abilities` | Твої здібності |
| `/coi menu native` | Перемикає між екранами [моду COI Client](/uk/guides/client-mod/) і меню-скринями |
| `/coi acting` | Перезарядки методів відіграшу й твій відіграш за джерелами. Дивись [Відіграш](/uk/magic/acting/) |
| `/bounty` (або `/coi bounty`) | Завдання відіграшу |
| `/ritual status` | Твій бал ритуалу для наступної Послідовності. Дивись [Ритуали](/uk/magic/rituals/) |
| `/ritual view <послідовність>` | Твої завдання ритуалу в меню, де можна попросити заміну |
| `/coi practice` | Потренуватися в міні-грі варіння без жодного ризику |
| `/coi tide` | Сьогоднішній Щоденний Приплив. `/coi tide calendar` показує найближчі дні. Дивись [Щоденні Припливи](/uk/guides/tides/) |

Гравці Високих Послідовностей також користуються `/coi usurp` ([Узурпація](/uk/magic/usurpation/)), `/coi ascend` і `/coi ascension` ([Послідовність 0](/uk/magic/sequence-zero/)) та `/coi church` ([Церкви](/uk/magic/churches/)).

## Гроші й крамниці

| Команда | Що робить |
|---|---|
| `/wallet` | Твої гроші. Дивись [Економіка](/uk/guides/economy/) |
| `/emporium` | [Блискучий Емпоріум](/uk/guides/emporium/) |
| `/daily` | Щоденні нагороди |
| `/vote` | Проголосувати за сервер |
| `/battlepass` (або `/bp`) | Battle Pass |
| `/calendar` | Календар нагород |
| `/tradeall` | Продати селянину всі свої інгредієнти за [Осколки Енергії](/uk/guides/economy/#осколки-енергії) |
| `/oga` | Подія Якорів Зовнішніх Богів і її крамниця нагород (`/oga rewards`) |

## Міста, групи й чат

| Команда | Що робить |
|---|---|
| `/lands` (або `/land`) | Створити місто й керувати ним. Дивись [Міста](/uk/guides/towns/) |
| `/nations` (або `/nation`) | Нації |
| `/wars` | Війни міст |
| `/o` | [Таємні Ордени](/uk/guides/orders/). `/oc` це чат Ордену |
| `/party` | Твоя група |
| `/msg <гравець> <повідомлення>` | Приватне повідомлення (також `/pm`, `/w`) |
| `/r` (або `/reply`) | Відповісти на останнє приватне повідомлення |
| `/ignore <гравець>` | Більше не бачити повідомлень гравця |
| `/titles` | Обрати титул |
| `/chatcolor` | Колір у чаті |

## Підземелля й події

| Команда | Що робить |
|---|---|
| `/subspace` | Усі підземелля, їхні входи й твої перезарядки. Дивись [Підземелля](/uk/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Група для підземелля, перевірка готовності, вихід із підземелля |
| `/cosmos` | [Вторгнення](/uk/guides/cosmos-incursions/), а також `/cosmos guide`, `status`, `shop`, `balance` і `leaderboard` |
| `/pvpevent join` | Приєднатися до події Duels або FFA, поки триває запис (`/pvpevent status` це показує) |
| `/bedwars` | Bedwars |
