## 第一步：

### 1. 连接服务器
- **服务器 IP**：`mc.mysterria.net`
- **Minecraft 版本**：1.21 - 26.1.2
- **服务器类型**：原版 + 插件，无需任何模组

![辅助图片](../../../../assets/start/ip-preview.png)

:::caution[请接受资源包！]
进入服务器时，**请接受资源包提示**。若不接受，所有自定义的魔法界面都不会显示，服务器看起来就和纯原版 Minecraft 一样。

如果你已经接受，但游戏看起来仍是原版，**请更新你的 Minecraft 客户端**——过旧的 Java 客户端可能会在不报错的情况下加载失败。

基岩版玩家可以通过 Geyser 连接，但部分自定义界面元素无法正确显示。这是已知的限制。
:::

### 2. 注册
- 执行命令 `/register <密码> <密码>`
- 请记住你的密码！
- 使用 `/login <密码>` 登录

附注：如果你拥有正版 Minecraft 账号，则完全无需注册！

### 3. Discord 验证
- 在[此处获取验证码 - https://www.mysterria.net/profile](https://www.mysterria.net/profile)

![辅助图片](../../../../assets/start/generate.png)
- 在 Minecraft 弹出的窗口中输入验证码

![辅助图片](../../../../assets/start/code.png)
- 完成验证后，你将获得以下奖励！

![辅助图片](../../../../assets/start/perks.png)

### 3. 新手奖励
- 你会看到一个包含游戏内全部途径的菜单

![辅助图片](../../../../assets/start/pathways.png)
- 任选其一，决定自己要走的道路，然后再次确认
- **捷径之路**直接授予你**序列 9**，但你的灵性上限将永久**降低 10%**，无法恢复
- **决心之路**不授予任何序列，但**保证你打开的下一个战利品箱中必出一份魔药配方**。之后你自行酿造第一瓶魔药，没有任何惩罚

:::note[途径的选择并非不可更改]
在此处选择途径只决定你的初始奖励。它**不会**让你成为非凡者，也**不会**把你锁定——若你日后找到并饮下其他途径的序列 9 魔药，你便转为那条途径。

只有当**途径图标出现在物品栏左上角**时，你才算非凡者，而这只会发生在你真正饮下魔药之后。至于初始奖励的选择，**事后无法更改**，请慎重决定。
:::

### 4. 基础命令
- `/magic` - 晋升的后续步骤（可选的辅助功能，不用它也能玩）
- `/subspace` - 列出所有地牢、其入口以及你的冷却时间
- `/emporium` - 打开璀璨商行（Brilliant Emporium）
- `/daily` - 在服务器游玩的每日奖励
- `/vote` - 打开服务器投票菜单
- `/bounty` - 打开赏金菜单以推进扮演进度
- `/wallet` - 打开你的货币钱包
- `/msg`、`/pm`、`/w` - 发送私聊消息
- `/reply` - 回复私聊消息
- `/lands` - 打开城镇管理菜单

:::caution[本服没有传送命令]
`/home`、`/sethome`、`/spawn`、`/tpa`、`/rtp` 和 `/back` 在 Mysterria **并不存在**，并且不会加入。赶路本身就该有意义——这正是**门**之类的移动系途径存在的理由。

请规划好行程，并谨慎选择定居之处。
:::

### 5. 查看你的进度

关于角色的一切都集中在一个地方：

> 打开**物品栏** → 点击左上角的**途径图标** → 在弹出的菜单中**将鼠标悬停在角色头部上**。

在那里你可以看到自己的序列、扮演进度、灵性与疯狂。

### 6. 最初的任务
1. 探索大厅。每个 NPC 都有自己的对话！
2. 熟悉服务器规则与维基内容
3. 创建自己的城镇，或加入他人的城镇
4. 选择你的魔法途径，投身冒险！

### 值得知道的事

- **世界只有一个主世界，大小为 15,000 × 15,000 格。**
- **野外是安全的。** PvP 只发生在专门的 PvP 区域和[宇宙侵袭](/zh-cn/guides/cosmos-incursions)区域内，你必须主动进入才会触发。破坏他人建筑违反规则。
- **所有自然生成的箱子都是魔法战利品容器**——村庄、废弃矿井、神殿、沉船等等。它们的内容**会随时间补充**，因此已被搜刮过的地点仍然值得再去。
- **世界大约每六个月重置一次**，进度也会一并重置。所以赛季中途加入从来都不算没有希望。
