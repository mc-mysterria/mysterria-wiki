下面是普通玩家在主服务器上可以使用的指令。Mysterria 的大部分功能都通过菜单操作，所以不在这张列表里的指令，玩家多半用不了。

## 不存在的指令

本服**没有** `/home`、`/sethome`、`/spawn`、`/tpa`、`/rtp` 或 `/back`。见[世界与安全](/zh-cn/general/world-and-safety/#有-homespawn-或-tpa-吗)。

## 入门

| 指令 | 作用 |
|---|---|
| `/register <password> <password>` | 注册离线账号（仅第一次进入时） |
| `/login <password>` | 登录离线账号 |
| `/verify` | 用[网站个人资料](https://www.mysterria.net/en/profile)里的验证码绑定账号 |
| `/magic` | 新手指南，包含**战利品定向**菜单 |
| `/guide` | 游戏内指南书 |
| `/faq` | 常见问题 |
| `/hints` | 游戏提示 |
| `/lang` | 更改插件消息的语言 |

## 你的非凡者

| 指令 | 作用 |
|---|---|
| `/coi menu character` | 你的角色界面，显示序列、扮演、生命值、灵性和疯狂值 |
| `/coi menu abilities` | 你的能力 |
| `/coi menu native` | 在 [COI 客户端](/zh-cn/guides/client-mod/)的界面和箱子菜单之间切换 |
| `/coi acting` | 扮演法的冷却时间，以及你各个来源的扮演进度。见[扮演](/zh-cn/magic/acting/) |
| `/bounty`（或 `/coi bounty`） | 扮演悬赏 |
| `/ritual status` | 你下一个序列的仪式得分。见[仪式](/zh-cn/magic/rituals/) |
| `/ritual view <sequence>` | 在菜单里查看你的仪式任务，还可以申请重新抽取 |
| `/coi practice` | 练习炼制小游戏，不会有任何损失 |
| `/coi tide` | 今天的每日潮汐。`/coi tide calendar` 显示接下来几天。见[每日潮汐](/zh-cn/guides/tides/) |

高序列玩家还会用到 `/coi usurp`（[篡位](/zh-cn/magic/usurpation/)）、`/coi ascend` 和 `/coi ascension`（[序列0](/zh-cn/magic/sequence-zero/)），以及 `/coi church`（[教会](/zh-cn/magic/churches/)）。

## 金钱与商店

| 指令 | 作用 |
|---|---|
| `/wallet` | 你的钱。见[经济](/zh-cn/guides/economy/) |
| `/emporium` | [璀璨商行](/zh-cn/guides/emporium/) |
| `/daily` | 每日奖励 |
| `/vote` | 为服务器投票 |
| `/battlepass`（或 `/bp`） | 战斗通行证 |
| `/calendar` | 奖励日历 |
| `/tradeall` | 把你的全部材料卖给村民，换取[能量碎片](/zh-cn/guides/economy/#能量碎片) |
| `/oga` | 外神锚点活动及其奖励商店（`/oga rewards`） |

## 城镇、团体与聊天

| 指令 | 作用 |
|---|---|
| `/lands`（或 `/land`） | 创建和管理城镇。见[城镇](/zh-cn/guides/towns/) |
| `/nations`（或 `/nation`） | 国家 |
| `/wars` | 城镇战争 |
| `/o` | [秘密组织](/zh-cn/guides/orders/)。`/oc` 是组织聊天 |
| `/party` | 你的队伍 |
| `/msg <player> <message>` | 私聊（也可以用 `/pm`、`/w`） |
| `/r`（或 `/reply`） | 回复上一条私聊 |
| `/ignore <player>` | 不再看到某位玩家的消息 |
| `/titles` | 选择称号 |
| `/chatcolor` | 聊天颜色 |

## 地牢与活动

| 指令 | 作用 |
|---|---|
| `/subspace` | 每个地牢、它的入口和你的冷却时间。见[地牢](/zh-cn/guides/dungeons/) |
| `/dparty`、`/ready`、`/leave` | 地牢队伍、准备确认、离开地牢 |
| `/cosmos` | [宇宙入侵](/zh-cn/guides/cosmos-incursions/)，还有 `/cosmos guide`、`status`、`shop`、`balance` 和 `leaderboard` |
| `/pvpevent join` | 在报名开放时加入决斗或大乱斗活动（`/pvpevent status` 可以查看） |
| `/bedwars` | 起床战争 |

## 其他

| 指令 | 作用 |
|---|---|
| `/sit`、`/lay` | 坐下或躺下 |
| `/uar` | 距离下一次服务器重启的时间 |
