**城镇**是你和朋友们共享的受保护土地。城镇之外的人都不能在那里建造、破坏方块或打开箱子。

所有城镇指令都以 `/lands`（或 `/land`）开头。单独输入 `/lands` 会打开城镇菜单，大部分事情在那里也能做。

## 怎样创建城镇？

```
/lands create <name>
```

- 它要花 **32 科佩**，从你的[钱包](/zh-cn/guides/economy/)里扣除。
- 它会免费圈下你周围 3 乘 3 的区块（你所在的区块，加上每个方向各一个）。
- 名字需要 5 到 24 个拉丁字母或数字。可以有空格。
- 你只能拥有**一个**城镇，也只能在一个城镇里被信任。

## 怎样圈更多的地？

```
/lands claim       圈下你所在的区块
/lands unclaim     取消圈定这个区块
```

| 项目 | 花费 |
|---|---|
| 每个额外的区块 | 10 科佩 |
| 取消圈定一个区块 | 退还 15% |

- 新圈的地必须**和你现有的土地相连**。
- 你不能在其他城镇周围 **1 个区块**以内圈地（如果那个城镇属于某个国家，则是 3 个区块），除非那个城镇允许你的身份在它的边界圈地。
- 城镇一开始可以圈 **100 个区块**，每有一名受信任的成员**再加 5 个**。更高的[等级](#城镇等级)会增加更多。
- 默认**只有城主**可以圈地。城主可以在身份设置里把这个权限给其他身份。

玩家无法使用 `/claim` 和 `/unclaim` 这两个简写指令。

## 基本城镇指令

| 指令 | 作用 |
|---|---|
| `/lands` | 打开城镇菜单 |
| `/lands trust <player>` | 邀请一位玩家。对方用 `/lands accept` 接受 |
| `/lands untrust <player>` | 移除一位玩家 |
| `/lands setrole <player> <role>` | 更改成员的身份 |
| `/lands ban <player>` | 禁止一位玩家进入你的土地 |
| `/lands deposit <amount>` | 把钱存进城镇银行 |
| `/lands withdraw <amount>` | 取钱（默认只有城主可以） |
| `/lands rename <name>` | 花 10,000 科佩给城镇改名，每天最多一次 |
| `/lands setowner <player>` | 从城镇银行花 5,000 科佩，把城镇交给别人 |
| `/lands upkeep`、`/lands taxes` | 查看下一次维护费和税款 |
| `/lands delete` | 解散你的城镇 |

**进入和离开消息**在城镇菜单里用 **Enter Message** 物品设置。没有 `/lands greeting` 或 `/lands farewell` 指令。

领地传送（`/lands spawn`、`/lands wild`、传送到某个区块）贵得离谱，实际上等于关闭了。Mysterria 没有 `/home` 或 `/tpa`。

想在城镇聊天里说话，就在消息前面加上 `!l`、`!land` 或 `!lands`。

## 城镇身份

每个身份决定了它的玩家在你的土地上能做什么。城主可以在城镇菜单里更改每个身份的权限。

| 身份 | 谁 | 默认权限 |
|---|---|---|
| **城主**（Owner） | 创建者 | 一切 |
| **管理员**（Admin） | 受信任的干部 | 建造、破坏、使用容器和门、信任、取消信任、封禁和设置身份、编辑领地和身份设置。默认不能圈地、取钱或管理战争 |
| **成员**（Member） | 普通居民 | 建造、破坏、种地、使用容器、存钱 |
| **租户**（Tenant） | 租用某片区域的玩家 | 在租用的区域里建造和使用东西，并决定还有谁可以使用 |
| **国家**（Nation） | 同一国家的成员 | 使用门和机关、进入、捡起物品、在你的边界圈地 |
| **盟友**（Ally） | 盟友城镇的成员 | 和国家相同 |
| **未信任**（Untrusted） | 任何访客 | 进入、捡起物品、攻击怪物 |

默认情况下，城镇里对所有身份都**关闭了 PvP**。城主可以按身份开启它，例如用于竞技场。

如果你攻击了另一名玩家，会被标记为战斗状态 **20 秒**。在被标记时下线会让你死亡。

## 经营城镇要花多少钱？

### 维护费

- 每个城镇每 **7 天**在 23:00 为**每个已圈区块支付 3 科佩**。这笔钱从城镇银行扣除，进入服务器银行 *The Narrator*。
- 新城镇在最初 **2 天**内不用付钱。
- 从付款前 2 天开始，如果银行余额不够，有存钱权限的成员每小时都会收到提醒。
- 如果银行付不起，你的区块**不会**被移除。
- 更高的[等级](#城镇等级)最多可以减少 40% 的维护费。

属于某个国家的城镇不向服务器支付维护费，而是向国家交税。见[国家与战争](/zh-cn/guides/nations-and-wars/)。

### 税收

城主可以在每个付款周期向受信任的成员收税，每块区域最多 **10 科佩**。付不起的成员会被自动取消信任。

## 城镇等级

城镇满足要求时会**自动**升级，不再满足时（例如银行余额下降）会**降一级**。每个等级都需要 **5 名受信任的玩家**，以及**城镇银行**（`/lands deposit`）里的一笔余额。

<Figure src={landsLevel} alt="Lands 的等级菜单，有两把挂锁，每把对应下一级的一项要求" caption="/lands 里的等级菜单。每把挂锁代表下一级的一项要求。" contain />

| 等级 | 名称 | 受信任的玩家 | 城镇银行 | 额外领地 | 额外成员名额 | 维护费 |
|---|---|---|---|---|---|---|
| 1 | **庇护所**（Shelter） | - | - | - | - | 全额 |
| 2 | **村落**（Hamlet） | 5 | 5,000 科佩 | +50 | +25 | -10% |
| 3 | **教区**（Parish） | 5 | 12,500 科佩 | +100 | +50 | -20% |
| 4 | **市镇**（Borough） | 5 | 25,000 科佩 | +150 | +75 | -30% |
| 5 | **领邦**（Domain） | 5 | 40,000 科佩 | +200 | +100 | -40% |

**领邦是最高等级。**城镇一开始有 26 个成员名额。

领邦可以建立[国家](/zh-cn/guides/nations-and-wars/)。

## 城镇对其他系统的意义

- 你可以在城镇领地里藏起自己的[集市](/zh-cn/guides/agora/)入口。
- [教会](/zh-cn/magic/churches/)可以把它们的金库和城镇关联起来。
- 拥有宏伟建筑的大型城镇可以获得[城镇增益](#城镇增益)。

## 城镇增益

**城镇增益**是一种永久的区域效果，城镇完成一项重大建筑工程后，由管理团队放置在城镇上。你无法购买它，也无法用指令领取。

### 怎样获得城镇增益？

1. 建造一座符合你想要的增益的宏伟建筑，例如一座大教堂、一座大图书馆或一道城墙。
2. 在 Discord 上提交支持工单，附上坐标和截图。
3. 管理团队会评估建筑质量、城镇的等级和人口。
4. 如果批准，管理团队会把增益放在你城镇的某片区域上。

### 有哪些增益？

| 增益 | 作用 | 城镇等级 | 受信任的玩家 | 半神 |
|---|---|---|---|---|
| **农业**（Agriculture） | 作物生长快得多 | 村落（2） | 5 | - |
| **怪物防护**（Mob Protection） | 区域内不会生成敌对怪物 | 市镇（4） | 12 | - |
| **药水效果**（Potion Effects） | 持续的效果，例如迅捷、急迫或夜视 | 领邦（5） | 18 | - |
| **经验加成**（Experience Boost） | 在区域内获得更多经验 | 领邦（5） | 22 | - |
| **盔甲修复**（Armor Repair） | 慢慢修复磨损的盔甲 | 领邦（5） | 30 | - |
| **扮演加成**（Acting Boost） | 站在区域内时扮演更快 | 领邦（5） | 40 | 3 |
| **灵性**（Spirituality） | 定时恢复灵性 | 领邦（5） | 45 | 5 |

- **受信任的玩家**是城镇里受信任的成员。**半神**是序列4或更强的受信任成员。
- 经验加成、盔甲修复、扮演加成和灵性以前要求城镇等级 6、8 和 10，这些等级已经不存在了。既然**领邦**现在是最高等级，这些增益就由玩家人数、半神人数和建筑本身来决定。

### 增益有多强？

每个增益都由管理团队针对它的城镇来设置，所以数值各不相同。目前服务器上生效的增益有：

- **扮演加成**在一个城镇给站在区域内的玩家 +18% 的扮演速度，在另一个城镇是 +45%。
- **灵性**在三个城镇每 20 秒恢复 50 点灵性，在一个城镇每 10 秒恢复 50 点，在另一个城镇每 10 秒恢复 30 点。
- **怪物防护**覆盖一个城镇中心周围半径 100 格的范围。

增益可以覆盖一座纪念碑周围的圆形区域、一座建筑周围的方形或其他形状区域，或者城镇的整个领地。

### 获得批准的窍门

建筑应该能让人联想到增益，就像龙的雕像适合怪物防护，大教堂适合灵性。小房子是不够格的。想想那种能定义整片地貌的世界奇观。管理团队会里里外外都检查，所以不要提交没完工的建筑或空壳子。
