**集市**（Agora）是藏在隐秘门后的地下市场，玩家在这里匿名地互相买卖。商品上不写名字，所以买家和卖家永远不知道对方是谁。

集市**没有任何指令**。你从一扇门走进去，然后右键点击在那里工作的人。

## 怎样进入集市？

### 使用公共入口

服务器在**坐标 (0, 0)** 设有一个**公共入口**。任何人都可以使用。右键点击门就能下去。

### 制作你自己的秘密入口

```
O E O        O = 黑曜石
E D E        E = 回响碎片
O E O        D = 深色橡木门
```

<Figure src={doorCraft} alt="黑曜石和回响碎片围着一扇深色橡木门摆在合成格里" caption="秘密入口的配方。" contain />

手持**秘密入口**右键点击一个方块，就能把它变成一扇绯红之门。只有满足下面的条件才有效：

- 这个位置上方有**两格空间**
- 它在某个[城镇](/zh-cn/guides/towns/)的**已圈领地**内，并且你在那里是**受信任**的
- 这块领地里还没有藏着一扇门，因为每块领地只允许**一个入口**

右键点击门就能下去。

### 它是秘密，不是锁

任何找到你这扇门的人都能走进去。把它藏好。

这扇门无法被破坏、炸毁或移动。唯一能去掉它的办法，是取消圈定它所在的领地。门每 30 分钟检查一次，如果连续第三次检查都发现它的领地没有被圈定，门就会被移除。只有当有玩家加载了那片区域时才会检查。所以只要附近有人，不再被圈定的领地上的入口大约一个半小时内就会消失。想要搬迁入口，就取消圈定那个区块，之后再重新圈定，然后放一个新制作的入口。旧的门永远不会回来。

### 怎样出来

右键点击**出口门**。你会在当初下去的地方回到地面。如果那个入口已经不在或者不安全，你会回到世界出生点。

## 里面有什么规则？

- **没有人会受伤。**没有 PvP，没有怪物，没有摔落伤害，没有爆炸，也没有火。
- **不能使用非凡能力。**它们在集市里无效。
- **没有捷径。**末影珍珠、紫颂果、鞘翅和载具都被禁止。你只能从出口门离开。
- **你的物品栏归你自己。**进出门时都不会拿走任何东西。
- **不能建造**，也不能打开容器，除非是在你租下的[摊位](#摊位)里。

## 集市里有谁在工作？

右键点击任何人就能和他们交谈。

| 谁 | 做什么 |
|---|---|
| **销赃人**（The Fence） | 把你的货物挂出去卖 |
| **集市店员**（Bazaar Clerk） | 浏览和购买 |
| **线人**（The Informant） | 按途径和序列搜索 |
| **账房**（Ledger Keeper） | 领取你买的东西和你的钱 |
| **信使驿站**（Courier Post） | 把买的东西送到你手上 |
| **摊位管理员**（Plot Warden） | 租用摊位 |
| **摊主**（Stall Keeper） | 租户自己的店面 |
| **军需官**（Quartermaster） | 建筑方块（以前的 `/shop`） |

## 价格怎么写？

价格使用服务器的[三种货币](/zh-cn/guides/economy/)。64 科佩等于 1 里克，64 里克（4,096 科佩）等于 1 因蒂费尔。

价格会以最简短的组合来显示，例如显示 `16 coppets 11 licks`，而不是 720 科佩。需要你自己输入价格的地方，用 `c` 表示科佩，`l` 表示里克，`v` 表示因蒂费尔。

## 怎样在集市里卖东西？

把物品交给**销赃人**并说出价格。他会先建议一个价格，非凡材料按序列估价，普通物品按类似东西的成交价估价。你可以不理会这个建议，随便定价。

| 规则 | 数值 |
|---|---|
| 挂单费 | 你定价的 **2%**（至少 1 科佩） |
| 交易税 | 成交额的 **8%** |
| 价格范围 | 1 到 1,000,000 科佩 |
| 每天新挂单 | **3** 个 |
| 同时在售的挂单 | **10** 个 |
| 挂单持续 | **72 小时** |

挂单费是**预先**支付的，无论物品卖掉、过期还是被取消，都不会退还。

### 什么东西不能卖？

- 潜影盒、收纳袋以及其他能装物品的东西
- 基岩
- 和你绑定的物品
- 历史契约的控制物品

### 东西卖出去时

你只会收到一条消息，说*有一枚钱币以你的名义被存了起来*，不会说卖了什么、卖了多少钱。到**账房**那里领取钱款。你离线时成交的交易也会等着你。

### 没卖出去时

72 小时后，没卖出去的挂单会过期，物品会进入你在账房那里的**储藏**。提前取消挂单，物品也会去同一个地方。

## 怎样在集市里买东西？

**集市店员**展示所有在售的商品。如果你知道自己想要什么，可以找**线人**按途径和序列搜索。

你只需支付标签上的价格，不用多付。税从卖家那一份里扣。你不能买自己的挂单。

买到的东西**不会进入你的物品栏**。它们会在账房那里等着，除非你在[信使驿站](#信使驿站)留了一个号角。

## 从账房领取

市场欠你的所有东西都会留在**账房**那里，直到你来领取。它们永远不会过期。

- **你的储藏**里有你买的物品、过期或被取消的挂单，以及从你失去的摊位里抢救出来的东西。你的物品栏有多少空间就拿多少，剩下的会继续留着。
- **你的账本**里有每笔交易扣税后的钱款。领取时会一次性付清所有欠款。

## 信使驿站

在**信使驿站**留下一个**召唤号角**，你**买**的所有东西都会由你的[信使](/zh-cn/guides/couriers/)送到你手上，无论你在哪里。

- 一次只能留一个号角。你随时都可以把它拿回来，之后就不再寄送。
- 寄送是免费的。号角就是代价。
- 你卖东西的钱不会被寄送。要到账房那里领取。

## 摊位

**摊位**是市场里一个可以租用、建造和出售东西的房间。找**摊位管理员**租一个。

<Figure src={plots} alt="集市的摊位区，灯笼照亮了四周" caption="摊位区。" />

| 规则 | 数值 |
|---|---|
| 租金 | **1 因蒂费尔**（4,096 科佩） |
| 租期 | **7 天** |
| 每位玩家的摊位 | **1** 个 |
| 宽限期 | **48 小时** |

付了租金之后，你可以在**你的摊位里**建造、破坏方块和使用箱子。你的店面会出现一位**摊主**。点击它的访客能看到你卖什么，你也会有自己的柜台。

### 保住你的摊位

在一周结束前再付一次钱给摊位管理员，就能续租一周。如果错过了，你会有 **48 小时的宽限期**，期间会收到提醒，所有东西都还在。

### 失去你的摊位

宽限期过后你会被收回摊位，但**任何东西都不会被销毁**。你箱子、物品展示框和盔甲架里的所有东西，以及留在地上的任何东西，都会进入你在账房那里的储藏。房间会被重置，留给下一位租户。

你也可以在摊位管理员的菜单里提前退租。

## 摊位柜台

**柜台**是摊位里箱子上的一块告示牌，它会卖东西给任何路过的人，没有挂单费，也不用等待。每个摊位最多可以有 **12 个**。

1. 放一个箱子，再在上面放一块告示牌（贴在正面或放在顶上）。
2. 在**第 1 行**写 `[Market]`。
3. 在**第 2 行**写价格，可以直接写科佩的数字，也可以用简写，例如 `3v 12l 5c`（3 因蒂费尔、12 里克和 5 科佩，也就是 13,061 科佩）。
4. 也可以在**第 3 行**写每次购买的数量，从 1 到 64。不写就是 1。
5. **手持你想卖的物品，右键点击告示牌。**

告示牌会重新显示为 **STALL COUNTER**，上面写着物品、价格和你的名字。

| 操作 | 结果 |
|---|---|
| 手持物品右键点击 | 设置或更改它卖的东西 |
| 空手右键点击 | 查看库存和总销量 |
| 潜行 + 右键点击 | 关闭柜台 |

**箱子就是你的库存。**补货就往里面多放东西。箱子空了，柜台就卖完了。想改价格，就破坏告示牌重新设置。

从柜台购买时，先右键点击告示牌一次查看价格，然后**在 6 秒内再点一次**付款。物品会直接到你手里。

告示牌、箱子或摊位任何一个没了，柜台就会关闭。

## 要花多少钱？

| 项目 | 花费 |
|---|---|
| 秘密入口 | 黑曜石、回响碎片和一扇深色橡木门 |
| 挂单一件物品 | 你定价的 2%（至少 1 科佩） |
| 卖出一件物品 | 成交额的 8% |
| 买一件物品 | 标签上的价格 |
| 租一个摊位 | 每周 1 因蒂费尔（4,096 科佩） |
| 信使寄送 | 免费（号角就是代价） |
