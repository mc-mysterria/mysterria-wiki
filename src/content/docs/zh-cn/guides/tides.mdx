每日潮汐是持续一天的全服加成。所有玩家同一时间只有一种潮汐生效，它们按固定的每周轮换进行，你可以提前做好安排。

## 潮汐什么时候变化？

一个潮汐日从**基辅时间 00:00 到 24:00**（Europe/Kyiv，冬季是 UTC+2，夏季是 UTC+3）。到了基辅时间午夜，无论你住在哪里，下一种潮汐都会对所有人开始。

## 七种潮汐是什么？

| 潮汐 | 作用 | 倍率 |
|---|---|---|
| **勤勉之潮**（Tide of Diligence） | 每次获得的扮演都翻倍 | 获得的扮演 x2 |
| **狩猎之潮**（Hunting Tide） | 生物生成和掉落更多，稀有材料更是多得多 | 生物生成 x2，生物掉落 x2，稀有材料 x3 |
| **幸运之潮**（Tide of Fortune） | 箱子更丰厚，保底更快 | 箱子战利品 x2.5，保底只需一半的开箱次数，稀有战利品 x2.5 |
| **狂野之潮**（Wild Tide） | 更多[野生非凡者](/zh-cn/magic/wild-beyonders/) | 野生非凡者生成 x2，野生非凡者上限 x2 |
| **耐心之潮**（Tide of Patience） | 扮演冷却减半 | 扮演冷却 x0.5 |
| **深潮**（Deep Tide） | 更多可采集节点，箱子里的材料也更多 | 可采集节点 x2，箱子里的材料 x2，稀有材料 x2 |
| **绯红之潮**（Crimson Tide） | [绯红之月](/zh-cn/magic/crimson-moon/)的几率提高到五倍 | 绯红之月几率 x5，生物掉落 x1.5 |

“稀有”指的是**序列3或更强**，也就是序列3、2和1。在狩猎之潮和深潮时，稀有材料加成适用于生物掉落和箱子里找到的材料，但不适用于可采集节点。

在绯红之潮时，每个夜晚出现绯红之月的几率是 **50%**，而不是平时的 10%。主世界的每个夜晚单独判定，所以玩上一整天，你很可能至少会遇到一次。

### 星期几是哪种潮汐？

轮换按照上表的顺序进行，所以每种潮汐每周都落在同一天：

| 日期（基辅时间） | 潮汐 |
|---|---|
| 星期一 | 狩猎之潮 |
| 星期二 | 幸运之潮 |
| 星期三 | 狂野之潮 |
| 星期四 | 耐心之潮 |
| 星期五 | 深潮 |
| 星期六 | 绯红之潮 |
| 星期日 | 勤勉之潮 |

管理团队可以更改轮换，或者把某一天固定成另一种潮汐，所以要确认的话，请在游戏里查看 `/coi tide calendar`。

### 加成叠加时有上限吗？

有。当好几种加成同时生效时，例如潮汐加上绯红之月，再加上药师途径的月亮权柄，总数是有上限的。

- 生物生成上限是 **x4**。
- 获得的扮演上限是 **x2.5**。

在勤勉之潮时，某个扮演来源达到上限后，多出来的部分会储存成溢出扮演，而不是填进你的扮演条。溢出扮演只在序列3及更强时存在，详见[篡位](/zh-cn/magic/usurpation/)。

## 哪种潮汐对我帮助最大？

- **前期和中期序列。**你的瓶颈是扮演条，所以**勤勉之潮**帮助最大。**狂野之潮**也有帮助，因为野生非凡者只存在于序列9到5。
- **序列3及更强。**比起扮演条，每个扮演法的冷却更拖你后腿，所以**耐心之潮**是属于你的日子。狩猎之潮、幸运之潮和深潮也带有针对你的稀有级加成。
- **搜刮。**开箱子留到**幸运之潮**，找材料留到**狩猎之潮**或**深潮**。

生物掉落加成对徽章生物和稀有材料最重要。自定义的[非凡生物](/zh-cn/magic/creatures/)本来几乎每次都会掉落它们的常见材料。

:::tip[幸运之潮与保底]
只有在你打开容器时才会检查保底。如果幸运之潮时你离保底阈值很近，就在午夜前再开一个箱子。无论如何你的计数都会保留，但阈值减半的效果会随着这一天结束。
:::

## 怎样知道今天是哪种潮汐？

- **登录卡片。**进入服务器几秒后，聊天栏里的一张卡片会显示潮汐、它的作用和剩余时间。
- **客户端弹窗。**如果你用 [COI 客户端](/zh-cn/guides/client-mod/)，同样的卡片会以弹窗形式出现。
- **每小时提醒。**每小时在聊天栏里显示一行，如果你刚进入服务器或者在挂机就会跳过。
- **Boss 血条。**到这一天结束的倒计时。
- **潮汐切换。**潮汐变化时，所有在线的人都会看到一个标题并听到一个音效。

## 有哪些指令？

| 指令 | 作用 |
|---|---|
| `/coi tide` 或 `/coi tide status` | 今天的潮汐、它的倍率和剩余时间 |
| `/coi tide calendar [days]` | 从今天开始接下来的潮汐（默认 14 天，最多 60 天） |
| `/coi tide notify` | 关闭或开启你的每小时提醒 |
| `/coi tide bar` | 关闭或开启你的潮汐 Boss 血条 |

## 潮汐永远不会改变什么？

| 系统 | 为什么不受影响 |
|---|---|
| [独一性](/zh-cn/magic/uniqueness/)评分 | 它按 31 天来衡量，所以你恰好在哪几天玩不应该有影响 |
| [篡位](/zh-cn/magic/usurpation/)的战争点数 | 点数按潮汐加成之前的数值计算 |
| 试炼 | 试炼可能让你失去物品栏，所以日历不应该改变几率 |
| 战斗伤害 | 平衡每天都保持一致 |
