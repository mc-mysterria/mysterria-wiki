**战斗通行证**会因为每日和每周任务给你点数，点数会提升你的等级。许多等级都带有奖励，例如金钱、能量碎片、商行点数、扮演之瓶、地牢钥匙，或者两条恩赐途径之一。

用 `/battlepass` 或 `/bp` 打开。

<Figure src={bpMain} alt="战斗通行证菜单，有 Rewards、Premium、Quests 和 Info 按钮" caption="战斗通行证菜单。" contain />

## 战斗通行证怎样运作？

1. 完成**每日任务**和**每周任务**来获得战斗通行证点数。
2. 一个等级的点数攒满后，你就进入下一级。
3. 到达奖励等级时，在战斗通行证菜单里打开 **Rewards**，**点击奖励来领取**。奖励不会自动发放。

每位玩家都有**免费通行证**。**高级通行证**会增加第二条奖励线，以及额外的高级专属任务。

<Figure src={bpRewards} alt="战斗通行证的 Rewards 页面，第 2 级的提示框列出 $200 和一个扮演之瓶" caption="Rewards 页面。把鼠标悬停在某一级上，可以看到它的奖励以及是否已经解锁。" contain />

## 任务

### 每日任务

- 你同一时间有 **9 个每日任务**，其中 4 个简单、3 个中等、2 个困难。
- 它们在每天**基辅时间 11:59** 重置。
- 每个任务值 **25 到 50 点**，例如驯服 3 只狼，或者达到 15 级经验。

### 每周任务

- 每 **7 天**解锁一周的新任务，时间是基辅时间周六 07:00。当前赛季从 2026 年 5 月 16 日开始，共 **26 周**。最后一周在 2026 年 11 月 7 日解锁。
- 之前几周的任务会一直开放，你不需要完成一周才能开始下一周。
- 大多数每周任务值 **95 点**。高级专属的每周任务值 **112 点**。

## 我需要多少点数？

| 等级 | 每级点数 |
|---|---|
| 普通等级 1 到 75 | 150 |
| 奖励等级 1 到 75 | 200 |
| 普通等级 76 到 100 | 150 |
| 奖励等级 76 到 100 | 350 |

加起来，**到达第 75 级需要 11,750 点**，**到达通行证终点第 100 级需要 16,900 点**。第 76 到 100 级是额外等级。高级通行证的奖励等级在不同的级数上，但数量一样多，所以总数相同。

## 这些奖励有什么用？

| 奖励 | 说明 |
|---|---|
| 科佩 | [金钱](/zh-cn/guides/economy/)，加到你的 `/wallet` 里 |
| 能量碎片 | 用于秘密组织和野生非凡者的[物品货币](/zh-cn/guides/economy/#能量碎片) |
| 商行点数 | 在[璀璨商行](/zh-cn/guides/emporium/)里使用 |
| 扮演之瓶 | 扔出去，为你当前的序列获得[扮演](/zh-cn/magic/acting/)点数 |
| 衰败君王恩赐途径、原初饥饿恩赐途径 | 一枚恩赐信物，解锁对应[恩赐途径](/zh-cn/magic/boons/)的序列9。你通过献祭非凡物品来提升它 |
| 配方纸 | 收集 3 或 4 张，组成一份完整的配方 |
| 配方代币 | 兑换序列4以内的任意配方 |
| 材料代币 | 兑换任意一种已知的材料 |
| 简易钥匙 | 一次单人重新进入[地牢](/zh-cn/guides/dungeons/)的机会 |
| 高级钥匙 | 一次整队重新进入地牢的机会 |
| 首领指南针 | 指向最近的[世界首领](/zh-cn/guides/bosses/)，使用后消耗 |
| 通用外观代币 | 给武器或工具换上自定义皮肤 |
| 聊天颜色礼包 | 365 天内在所有聊天频道使用颜色和格式 |

## 怎样获得高级通行证？

**Premium BattlePass** 在[服务器商店](https://www.mysterria.net/en/store)出售。它会解锁上面的高级奖励线和高级专属的每周任务。
