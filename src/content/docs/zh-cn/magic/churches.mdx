**教会**是由玩家经营的宗教，围绕一位领袖、一条途径、祈祷的成员和实际的教会地点建立起来。教会保持活跃时，它的成员会得到越来越强的扮演和疯狂值加成。

经营教会地点、分部和教会战争，见[教会管理](/zh-cn/magic/church-management/)。具体的加成数值见[教会增益与锚点](/zh-cn/magic/church-perks/)。

## 教会能给成员什么？

- 在你正常获得的扮演之外，额外的**扮演加成**。
- **疯狂值恢复加成**，让可恢复的疯狂值降得更快。
- 序列4及更强的成员能获得**疯狂底线减轻**（见[下文](#疯狂底线减轻)）。
- 教会干部的**祝福**和**恩惠**，在疯狂值、疲劳和灵性方面给予支持。
- 教会地点附近的**祈祷效果**。
- 共享的**教会金库**，用来存放[封印物](/zh-cn/magic/sealed-artifacts/)。
- **危险警报**，当有成员遇到麻烦时，通知领袖、副领袖、天使和首席执事。

这些都不是固定数值。它们会随着活跃成员、最近的祈祷、地点活跃度、途径匹配以及其他教会健康的迹象而增长。

## 怎样创立教会？

你需要：

| 要求 | 数值 |
|---|---|
| 非凡者 | 是 |
| 序列 | **4 或更强** |
| 当前教会 | 你不能是另一个教会的成员、领袖或副领袖 |
| 冷却 | 你上次离开、被移出或解散教会后 **14 天** |

每个教会都从一个**教会核心**开始。

1. 制作一个教会核心（配方见下文）。
2. 把它放在你的主教会地点所在的位置。
3. 按提示在聊天栏里输入教会的名字。
4. 点击核心或使用 `/coi church menu` 来管理教会。

## 怎样加入教会？

- 教会领袖或副领袖用 `/coi church add <player>` 邀请你。在 **5 分钟**内用 `/coi church accept` 接受。
- 如果你诵念了某位教会成员的[尊名](/zh-cn/magic/honorific-names/)，对方也可以向你发出邀请。

成员没有上限。任何人都可以加入，包括其他途径的玩家和普通人，但教会自己途径的成员算得最多。离开教会后的 14 天冷却同样适用于加入新教会。

新成员不会马上得到全部增益。你从 **20%** 开始，**14 天**后达到完整数值（如果你是从另一个教会转过来的，则是 21 天）。

### 离开

使用 `/coi church leave`。领袖不能离开。领袖必须先用 `/coi church ownership handoff <player> confirm` 把教会交给别人，或者用 `/coi church disband` 解散它（之后你有 45 秒，在聊天栏里准确输入教会名字来确认）。

## 怎样祈祷？

祈祷让教会的加成保持生效。成员 **14 天**没有祈祷，或者 14 天没有登录，就不再计入教会。

你可以这样祈祷：

- `/coi church pray`
- 教会菜单里的祈祷按钮
- 在聊天栏里逐行诵念教会任意一位成员的完整[尊名](/zh-cn/magic/honorific-names/)（这算作外部祈祷）

| 祈祷规则 | 数值 |
|---|---|
| 全额生效范围 | 活跃教会地点 **100 格**以内 |
| 远离教会地点时 | 按 **10%** 的强度计算 |
| 祈祷连接持续 | **30 分钟** |
| 祈祷效果冷却 | **12 小时** |

祈祷消息会准确地告诉你得到了什么。如果你觉得增益很弱，首先要做的就是让成员在教会地点附近祈祷。

## 教会的各个身份有什么作用？

| 身份 | 作用 |
|---|---|
| **领袖** | 拥有教会并设定它的途径。放置核心，管理成员、地点和天使。不算作自己教会的锚点 |
| **副领袖** | 对大多数教会系统拥有和领袖相近的权限。最多 **2** 名。可以管理区域总部。不算作成员锚点 |
| **天使** | 需要**序列3**或更强。拥有强力的祝福、恩惠和金库权限。名额为 **3** 个，每个活跃的分部再加 1 个。如果天使人数超过名额，天使的效果会暂停 |
| **首席执事** | 负责一个教会地点，并保证它有人照看 |
| **主教** | 协助一个地点。每个地点最多 **2** 名 |
| **区域经理** | 负责一个区域总部 |
| **信徒** | 祈祷并提供锚点权重。3 天后成为初级信徒，7 天后成为信徒，14 天后成为资深信徒 |

地点相关的身份见[教会管理](/zh-cn/magic/church-management/)。

## 教会聊天

用 `/coi church chat <message>` 和整个教会说话，或者在普通聊天消息前加上 `!c`、`!cc` 或 `!church`，例如 `!c meet at the cathedral`。

## 疯狂底线减轻

从序列4开始，每个非凡者都有一条神性疯狂底线，也就是恢复手段无法消除的那部分疯狂值。一个健康的教会会为成员降低这条底线，对领袖和副领袖的效果最强。例如，一位新神在信众增长起来之前，底线大约在 30%。

各条底线、减轻公式和各身份的上限，见[教会增益与锚点](/zh-cn/magic/church-perks/#疯狂底线减轻)。疯狂值的一般说明见[疯狂与异变](/zh-cn/magic/mutation/)。

<Notice tone="info" title="猎人途径的部众">
猎人途径的[指挥链部众](/zh-cn/magic/sequence-zero/#猎人途径的部众可以代替教会)会给没有活跃教会的成员提供它自己的底线减轻。那不是教会身份。
</Notice>

## 教会与神

在通往[序列0](/zh-cn/magic/sequence-zero/)的路上，教会非常重要。宣告者需要自己的教会承载 **20** 个锚点，而且必须是教会的领袖、副领袖或天使。参加 **10** 次教会礼拜也是传奇事迹之一。

一旦有神坐上神座，教会成员身份本身不会带来任何属性加成。它只是让神能用**谕令**找到你。每位成员都有一个虔诚开关。关闭是立刻生效的，但重新打开要等一周。

## 在哪里找到教会菜单？

- `/coi church menu`，或者点击你的教会核心
- 角色菜单 `/coi menu character` 里的教会栏位（一个信标）
- [COI 客户端](/zh-cn/guides/client-mod/)里的教会菜单（默认按键 M）

## 成员指令

| 指令 | 作用 |
|---|---|
| `/coi church menu` | 打开教会菜单 |
| `/coi church accept` | 接受最近的邀请 |
| `/coi church leave` | 离开你的教会 |
| `/coi church pray` | 祈祷 |
| `/coi church chat <message>` | 教会聊天（或者 `!c <message>`） |
| `/coi church info` | 你教会的详细信息 |
| `/coi church members` | 成员列表 |
| `/coi church status` | 教会健康状况一览 |
| `/coi church perks` | 你当前的增益以及限制它们的因素 |
| `/coi church acting` | 你的教会扮演加成 |
| `/coi church pathway progress` | 对你自己途径的支持 |
| `/coi church pathway <pathway> progress` | 对你教会中另一条途径的支持 |
| `/coi church my-site` | 你被分配的教会地点 |
| `/coi church cooldowns` | 你的教会冷却 |
| `/coi church top [pathway]` | 最强的教会，可以看总榜或某一条途径 |
| `/coi church vault` | 打开教会金库 |
| `/coi church artifacts list` | 你的教会存放的封印物 |
| `/coi church artifact request <artifactId>` | 申请借用一件封印物 |
| `/coi church artifact return` | 归还借用的封印物 |

领袖和管理者的指令见[教会管理](/zh-cn/magic/church-management/#领袖和管理者指令)。
