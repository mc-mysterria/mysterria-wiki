**灵性**是你的能力所消耗的能量，它会随时间自动恢复。灵性耗尽不会让你死亡，但会把你推向疯狂。

它显示在屏幕顶部的蓝色条上（或 [COI 客户端](/zh-cn/guides/client-mod/)的可移动灵性条上），也显示在角色界面上（`/coi menu character`）。

## 我有多少灵性？

你的灵性上限这样计算：

**上限 = 你所在序列的基础值 × (0.5 + 0.5 × 你的扮演进度) × 你途径的倍率**

刚晋升完、扮演为 0% 时，你只有完整上限的**一半**。随着扮演，它会逐渐增加，扮演达到 100% 时达到完整数值。到了序列0，它总是按满值计算。

| 序列 | 基础值 |
|---|---:|
| 9 | 100 |
| 8 | 250 |
| 7 | 500 |
| 6 | 1,000 |
| 5 | 2,500 |
| 4 | 5,000 |
| 3 | 10,000 |
| 2 | 25,000 |
| 1 | 70,000 |
| 0 | 100,000 |

### 途径倍率

这里没有列出的途径倍率都是 x1.0。

| 途径 | 各序列的倍率 |
|---|---|
| 占卜家 | 9 为 x1.1，8 为 x1.15，7 为 x1.2，6 到 5 为 x1.25，4 到 3 为 x1.4，2 到 0 为 x1.6 |
| 药师 | 9 到 3 为 x1.08，2 为 x1.7，1 为 x1.8，0 为 x1.89 |
| 学徒 | 9 到 8 为 x1.0，7 到 5 为 x1.2，4 到 3 为 x1.35，2 为 x1.5，1 到 0 为 x1.65 |
| 猎人 | 9 为 x1.02，8 为 x1.08，7 为 x1.15，6 为 x1.25，5 到 4 为 x1.3，3 为 x1.4，2 到 0 为 x1.55 |
| 怪物 | 9 为 x1.1，8 到 7 为 x1.15，6 为 x1.4，5 到 0 为 x1.45 |
| 不眠者 | 9 到 7 为 x1.15，6 到 0 为 x1.3 |
| 收尸人 | 9 为 x1.1，8 为 x1.15，7 到 0 为 x1.2 |
| 秘祈人 | 9 为 x1.05，8 到 0 为 x1.12 |
| 战士 | 9 到 5 为 x1.0，4 到 0 为 x1.2 |

药师途径的神灵大约有 189,000 灵性，而扮演已满的序列9占卜家有 110。

### 还有什么会改变我的上限？

- [恩赐途径](/zh-cn/magic/boons/)会在你的途径之上额外增加一部分。
- **捷径之路**（一种新手奖励）会让你的上限**永久降低 10%**，每个序列都是如此。见[快速开始](/zh-cn/general/start/#4-选择新手奖励)。
- 违反歌颂者途径的**公证**契约，可能会受到**灵性束缚**的惩罚，它同样会让你的上限降低 10%。
- **独一性**和一些被动能力会提高上限。不眠者途径非凡者的“夜之眷顾”会在夜晚提高上限。

## 灵性恢复得有多快？

你每秒恢复**上限的 1/400 再加 1**。拥有 100 灵性的序列9非凡者每秒大约恢复 1 点，拥有 5,000 灵性的序列4每秒大约恢复 13 点。没有任何减速时，空的灵性条不到 7 分钟就能恢复满。

疯狂值和疲劳会减慢恢复速度，两者的效果会叠加。

| 疯狂值 | 恢复速度 |
|---|---|
| 低于 25% | 全速 |
| 25% 或以上 | 80% |
| 50% 或以上 | 60% |
| 75% 或以上 | 30% |

| 疲劳 | 恢复速度 |
|---|---|
| 低于 65 | 全速 |
| 65 或以上 | 85% |
| 85 或以上 | 70% |

疯狂值 75% 再加上疲劳 85 时，你的恢复速度只有 21%。

### 更快恢复的方法

- **灵性主义**（Spiritualism，占卜家途径和不眠者途径的序列9）每 5 秒恢复你上限的 1%。
- 即使你拥有好几个灵性恢复类的被动能力，同一时间也只能开启**一个**。
- **灵性药水**会立刻恢复你的一部分灵性。在[地牢](/zh-cn/guides/dungeons/)的援助卡兑换里可以买到。
- 教会可以赐予**灵性恢复**的恩惠。见[教会](/zh-cn/magic/churches/)。

## 灵性不足时会怎样？

- 灵性**低于 10%** 时，每持续 2.5 分钟，就会增加 **1% 的疯狂值**。
- 如果施法时灵性不够，游戏会让你用疯狂值来支付缺少的部分，**每缺 1 点灵性就增加 0.2% 疯狂值**。如果这会让你的疯狂值达到 90% 或以上，施法就会被拒绝，而且被拒绝时你所有开启中的能力也会关闭。
- **灵性为 0 时**，所有开启中的能力都会关闭。

到了高序列，一次施法就可能消耗几千点灵性。疯狂值的作用见[疯狂与异变](/zh-cn/magic/mutation/)，疲劳见[状态](/zh-cn/magic/conditions/)。
