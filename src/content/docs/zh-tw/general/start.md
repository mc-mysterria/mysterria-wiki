## 第一步：

### 1. 連線到伺服器
- **伺服器 IP**：`mc.mysterria.net`
- **Minecraft 版本**：1.21 - 26.1.2
- **伺服器類型**：原版 + 外掛，無需任何模組

![輔助圖片](../../../../assets/start/ip-preview.png)

:::caution[請接受資源包！]
進入伺服器時，**請接受資源包提示**。若不接受，所有自訂的魔法介面都不會顯示，伺服器看起來就和純原版 Minecraft 一樣。

如果你已經接受，但遊戲看起來仍是原版，**請更新你的 Minecraft 客戶端**——過舊的 Java 客戶端可能會在不報錯的情況下載入失敗。

基岩版玩家可以透過 Geyser 連線，但部分自訂介面元素無法正確顯示。這是已知的限制。
:::

### 2. 註冊
- 執行指令 `/register <密碼> <密碼>`
- 請記住你的密碼！
- 使用 `/login <密碼>` 登入

附註：如果你擁有正版 Minecraft 帳號，則完全無需註冊！

### 3. Discord 驗證
- 在[此處取得驗證碼 - https://www.mysterria.net/profile](https://www.mysterria.net/profile)

![輔助圖片](../../../../assets/start/generate.png)
- 在 Minecraft 彈出的視窗中輸入驗證碼

![輔助圖片](../../../../assets/start/code.png)
- 完成驗證後，你將獲得以下獎勵！

![輔助圖片](../../../../assets/start/perks.png)

### 3. 新手獎勵
- 你會看到一個包含遊戲內全部途徑的選單

![輔助圖片](../../../../assets/start/pathways.png)
- 任選其一，決定自己要走的道路，然後再次確認
- **捷徑之路**直接授予你**序列 9**，但你的靈性上限將永久**降低 10%**，無法恢復
- **決心之路**不授予任何序列，但**保證你打開的下一個戰利品箱中必出一份魔藥配方**。之後你自行釀造第一瓶魔藥，沒有任何懲罰

:::note[途徑的選擇並非不可更改]
在此處選擇途徑只決定你的初始獎勵。它**不會**讓你成為非凡者，也**不會**把你鎖定——若你日後找到並飲下其他途徑的序列 9 魔藥，你便轉為那條途徑。

只有當**途徑圖示出現在物品欄左上角**時，你才算非凡者，而這只會發生在你真正飲下魔藥之後。至於初始獎勵的選擇，**事後無法更改**，請慎重決定。
:::

### 4. 基礎指令
- `/magic` - 晉升的後續步驟（可選的輔助功能，不用它也能玩）
- `/subspace` - 列出所有地城、其入口以及你的冷卻時間
- `/emporium` - 開啟璀璨商行（Brilliant Emporium）
- `/daily` - 在伺服器遊玩的每日獎勵
- `/vote` - 開啟伺服器投票選單
- `/bounty` - 開啟懸賞選單以推進扮演進度
- `/wallet` - 開啟你的貨幣錢包
- `/msg`、`/pm`、`/w` - 傳送私訊
- `/reply` - 回覆私訊
- `/lands` - 開啟城鎮管理選單

:::caution[本伺服器沒有傳送指令]
`/home`、`/sethome`、`/spawn`、`/tpa`、`/rtp` 和 `/back` 在 Mysterria **並不存在**，而且不會加入。趕路本身就該有意義——這正是**門**之類的移動系途徑存在的理由。

請規劃好行程，並謹慎選擇定居之處。
:::

### 5. 查看你的進度

關於角色的一切都集中在一個地方：

> 開啟**物品欄** → 點擊左上角的**途徑圖示** → 在彈出的選單中**將滑鼠停留在角色頭部上**。

在那裡你可以看到自己的序列、扮演進度、靈性與瘋狂。

### 6. 最初的任務
1. 探索大廳。每個 NPC 都有自己的對話！
2. 熟悉伺服器規則與維基內容
3. 建立自己的城鎮，或加入他人的城鎮
4. 選擇你的魔法途徑，投身冒險！

### 值得知道的事

- **世界只有一個主世界，大小為 15,000 × 15,000 格。**
- **野外是安全的。** PvP 只發生在專門的 PvP 區域和[宇宙侵襲](/zh-tw/guides/cosmos-incursions)區域內，你必須主動進入才會觸發。破壞他人建築違反規則。
- **所有自然生成的箱子都是魔法戰利品容器**——村莊、廢棄礦坑、神殿、沉船等等。它們的內容**會隨時間補充**，因此已被搜刮過的地點仍然值得再去。
- **世界大約每六個月重置一次**，進度也會一併重置。所以賽季中途加入從來都不算沒有希望。

## 實用建議

- 請隨時留意聊天頻道，那裡有大量有用資訊
- 有問題就在聊天裡問，不要猶豫！若當下沒人，稍後也會有人幫你
- 加入 Discord 社群。那裡有最新公告、城鎮論壇等等！
- 循序漸進地了解魔法體系。可以看動畫，也可以嘗試閱讀網路小說！

## 需要幫助？

如果你有疑問，請在聊天頻道或 Discord 聯繫其他玩家或管理組！
