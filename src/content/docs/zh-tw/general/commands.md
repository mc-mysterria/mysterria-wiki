下面是普通玩家在主伺服器上可以使用的指令。Mysterria 的大部分功能都透過選單操作，所以不在這張列表裡的指令，玩家多半用不了。

## 不存在的指令

本服**沒有** `/home`、`/sethome`、`/spawn`、`/tpa`、`/rtp` 或 `/back`。見[世界與安全](/zh-tw/general/world-and-safety/#有-homespawn-或-tpa-嗎)。

## 入門

| 指令 | 作用 |
|---|---|
| `/register <password> <password>` | 註冊離線帳號（僅第一次進入時） |
| `/login <password>` | 登入離線帳號 |
| `/verify` | 用[網站個人資料](https://www.mysterria.net/en/profile)裡的驗證碼綁定帳號 |
| `/magic` | 新手指南，包含**戰利品定向**選單 |
| `/guide` | 遊戲內指南書 |
| `/faq` | 常見問題 |
| `/hints` | 遊戲提示 |
| `/lang` | 更改外掛訊息的語言 |

## 你的非凡者

| 指令 | 作用 |
|---|---|
| `/coi menu character` | 你的角色介面，顯示序列、扮演、生命值、靈性和瘋狂值 |
| `/coi menu abilities` | 你的能力 |
| `/coi menu native` | 在 [COI 客戶端](/zh-tw/guides/client-mod/)的介面和箱子選單之間切換 |
| `/coi acting` | 扮演法的冷卻時間，以及你各個來源的扮演進度。見[扮演](/zh-tw/magic/acting/) |
| `/bounty`（或 `/coi bounty`） | 扮演懸賞 |
| `/ritual status` | 你下一個序列的儀式得分。見[儀式](/zh-tw/magic/rituals/) |
| `/ritual view <sequence>` | 在選單裡檢視你的儀式任務，還可以申請重新抽取 |
| `/coi practice` | 練習煉製小遊戲，不會有任何損失 |
| `/coi tide` | 今天的每日潮汐。`/coi tide calendar` 顯示接下來幾天。見[每日潮汐](/zh-tw/guides/tides/) |

高序列玩家還會用到 `/coi usurp`（[篡位](/zh-tw/magic/usurpation/)）、`/coi ascend` 和 `/coi ascension`（[序列0](/zh-tw/magic/sequence-zero/)），以及 `/coi church`（[教會](/zh-tw/magic/churches/)）。

## 金錢與商店

| 指令 | 作用 |
|---|---|
| `/wallet` | 你的錢。見[經濟](/zh-tw/guides/economy/) |
| `/emporium` | [璀璨商行](/zh-tw/guides/emporium/) |
| `/daily` | 每日獎勵 |
| `/vote` | 為伺服器投票 |
| `/battlepass`（或 `/bp`） | 戰鬥通行證 |
| `/calendar` | 獎勵日曆 |
| `/tradeall` | 把你的全部材料賣給村民，換取[能量碎片](/zh-tw/guides/economy/#能量碎片) |
| `/oga` | 外神錨點活動及其獎勵商店（`/oga rewards`） |

## 城鎮、團體與聊天

| 指令 | 作用 |
|---|---|
| `/lands`（或 `/land`） | 建立和管理城鎮。見[城鎮](/zh-tw/guides/towns/) |
| `/nations`（或 `/nation`） | 國家 |
| `/wars` | 城鎮戰爭 |
| `/o` | [秘密組織](/zh-tw/guides/orders/)。`/oc` 是組織聊天 |
| `/party` | 你的隊伍 |
| `/msg <player> <message>` | 私聊（也可以用 `/pm`、`/w`） |
| `/r`（或 `/reply`） | 回覆上一條私聊 |
| `/ignore <player>` | 不再看到某位玩家的訊息 |
| `/titles` | 選擇稱號 |
| `/chatcolor` | 聊天顏色 |

## 地牢與活動

| 指令 | 作用 |
|---|---|
| `/subspace` | 每個地牢、它的入口和你的冷卻時間。見[地牢](/zh-tw/guides/dungeons/) |
| `/dparty`、`/ready`、`/leave` | 地牢隊伍、準備確認、離開地牢 |
| `/cosmos` | [宇宙入侵](/zh-tw/guides/cosmos-incursions/)，還有 `/cosmos guide`、`status`、`shop`、`balance` 和 `leaderboard` |
| `/pvpevent join` | 在報名開放時加入決鬥或大亂鬥活動（`/pvpevent status` 可以檢視） |
| `/bedwars` | 起床戰爭 |

## 其他

| 指令 | 作用 |
|---|---|
| `/sit`、`/lay` | 坐下或躺下 |
| `/uar` | 距離下一次伺服器重啟的時間 |
