**靈性**是你的能力所消耗的能量，它會隨時間自動恢復。靈性耗盡不會讓你死亡，但會把你推向瘋狂。

它顯示在螢幕頂部的藍色條上（或 [COI 客戶端](/zh-tw/guides/client-mod/)的可移動靈性條上），也顯示在角色介面上（`/coi menu character`）。

## 我有多少靈性？

你的靈性上限這樣計算：

**上限 = 你所在序列的基礎值 × (0.5 + 0.5 × 你的扮演進度) × 你途徑的倍率**

剛晉升完、扮演為 0% 時，你只有完整上限的**一半**。隨著扮演，它會逐漸增加，扮演達到 100% 時達到完整數值。到了序列0，它總是按滿值計算。

| 序列 | 基礎值 |
|---|---:|
| 9 | 100 |
| 8 | 250 |
| 7 | 500 |
| 6 | 1,000 |
| 5 | 2,500 |
| 4 | 5,000 |
| 3 | 10,000 |
| 2 | 25,000 |
| 1 | 70,000 |
| 0 | 100,000 |

### 途徑倍率

這裡沒有列出的途徑倍率都是 x1.0。

| 途徑 | 各序列的倍率 |
|---|---|
| 占卜家 | 9 為 x1.1，8 為 x1.15，7 為 x1.2，6 到 5 為 x1.25，4 到 3 為 x1.4，2 到 0 為 x1.6 |
| 藥師 | 9 到 3 為 x1.08，2 為 x1.7，1 為 x1.8，0 為 x1.89 |
| 學徒 | 9 到 8 為 x1.0，7 到 5 為 x1.2，4 到 3 為 x1.35，2 為 x1.5，1 到 0 為 x1.65 |
| 獵人 | 9 為 x1.02，8 為 x1.08，7 為 x1.15，6 為 x1.25，5 到 4 為 x1.3，3 為 x1.4，2 到 0 為 x1.55 |
| 怪物 | 9 為 x1.1，8 到 7 為 x1.15，6 為 x1.4，5 到 0 為 x1.45 |
| 不眠者 | 9 到 7 為 x1.15，6 到 0 為 x1.3 |
| 收屍人 | 9 為 x1.1，8 為 x1.15，7 到 0 為 x1.2 |
| 秘祈人 | 9 為 x1.05，8 到 0 為 x1.12 |
| 戰士 | 9 到 5 為 x1.0，4 到 0 為 x1.2 |

藥師途徑的神靈大約有 189,000 靈性，而扮演已滿的序列9占卜家有 110。

### 還有什麼會改變我的上限？

- [恩賜途徑](/zh-tw/magic/boons/)會在你的途徑之上額外增加一部分。
- **捷徑之路**（一種新手獎勵）會讓你的上限**永久降低 10%**，每個序列都是如此。見[快速開始](/zh-tw/general/start/#4-選擇新手獎勵)。
- 違反歌頌者途徑的**公證**契約，可能會受到**靈性束縛**的懲罰，它同樣會讓你的上限降低 10%。
- **獨一性**和一些被動能力會提高上限。不眠者途徑非凡者的“夜之眷顧”會在夜晚提高上限。

## 靈性恢復得有多快？

你每秒恢復**上限的 1/400 再加 1**。擁有 100 靈性的序列9非凡者每秒大約恢復 1 點，擁有 5,000 靈性的序列4每秒大約恢復 13 點。沒有任何減速時，空的靈性條不到 7 分鐘就能恢復滿。

瘋狂值和疲勞會減慢恢復速度，兩者的效果會疊加。

| 瘋狂值 | 恢復速度 |
|---|---|
| 低於 25% | 全速 |
| 25% 或以上 | 80% |
| 50% 或以上 | 60% |
| 75% 或以上 | 30% |

| 疲勞 | 恢復速度 |
|---|---|
| 低於 65 | 全速 |
| 65 或以上 | 85% |
| 85 或以上 | 70% |

瘋狂值 75% 再加上疲勞 85 時，你的恢復速度只有 21%。

### 更快恢復的方法

- **靈性主義**（Spiritualism，占卜家途徑和不眠者途徑的序列9）每 5 秒恢復你上限的 1%。
- 即使你擁有好幾個靈性恢復類的被動能力，同一時間也只能開啟**一個**。
- **靈性藥水**會立刻恢復你的一部分靈性。在[地牢](/zh-tw/guides/dungeons/)的援助卡兌換裡可以買到。
- 教會可以賜予**靈性恢復**的恩惠。見[教會](/zh-tw/magic/churches/)。

## 靈性不足時會怎樣？

- 靈性**低於 10%** 時，每持續 2.5 分鐘，就會增加 **1% 的瘋狂值**。
- 如果施法時靈性不夠，遊戲會讓你用瘋狂值來支付缺少的部分，**每缺 1 點靈性就增加 0.2% 瘋狂值**。如果這會讓你的瘋狂值達到 90% 或以上，施法就會被拒絕，而且被拒絕時你所有開啟中的能力也會關閉。
- **靈性為 0 時**，所有開啟中的能力都會關閉。

到了高序列，一次施法就可能消耗幾千點靈性。瘋狂值的作用見[瘋狂與異變](/zh-tw/magic/mutation/)，疲勞見[狀態](/zh-tw/magic/conditions/)。
