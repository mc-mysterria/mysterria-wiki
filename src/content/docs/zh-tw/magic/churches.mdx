**教會**是由玩家經營的宗教，圍繞一位領袖、一條途徑、祈禱的成員和實際的教會地點建立起來。教會保持活躍時，它的成員會得到越來越強的扮演和瘋狂值加成。

經營教會地點、分部和教會戰爭，見[教會管理](/zh-tw/magic/church-management/)。具體的加成數值見[教會增益與錨點](/zh-tw/magic/church-perks/)。

## 教會能給成員什麼？

- 在你正常獲得的扮演之外，額外的**扮演加成**。
- **瘋狂值恢復加成**，讓可恢復的瘋狂值降得更快。
- 序列4及更強的成員能獲得**瘋狂底線減輕**（見[下文](#瘋狂底線減輕)）。
- 教會幹部的**祝福**和**恩惠**，在瘋狂值、疲勞和靈性方面給予支援。
- 教會地點附近的**祈禱效果**。
- 共享的**教會金庫**，用來存放[封印物](/zh-tw/magic/sealed-artifacts/)。
- **危險警報**，當有成員遇到麻煩時，通知領袖、副領袖、天使和首席執事。

這些都不是固定數值。它們會隨著活躍成員、最近的祈禱、地點活躍度、途徑匹配以及其他教會健康的跡象而增長。

## 怎樣創立教會？

你需要：

| 要求 | 數值 |
|---|---|
| 非凡者 | 是 |
| 序列 | **4 或更強** |
| 當前教會 | 你不能是另一個教會的成員、領袖或副領袖 |
| 冷卻 | 你上次離開、被移出或解散教會後 **14 天** |

每個教會都從一個**教會核心**開始。

1. 製作一個教會核心（配方見下文）。
2. 把它放在你的主教會地點所在的位置。
3. 按提示在聊天欄裡輸入教會的名字。
4. 點選核心或使用 `/coi church menu` 來管理教會。

## 怎樣加入教會？

- 教會領袖或副領袖用 `/coi church add <player>` 邀請你。在 **5 分鐘**內用 `/coi church accept` 接受。
- 如果你誦唸了某位教會成員的[尊名](/zh-tw/magic/honorific-names/)，對方也可以向你發出邀請。

成員沒有上限。任何人都可以加入，包括其他途徑的玩家和普通人，但教會自己途徑的成員算得最多。離開教會後的 14 天冷卻同樣適用於加入新教會。

新成員不會馬上得到全部增益。你從 **20%** 開始，**14 天**後達到完整數值（如果你是從另一個教會轉過來的，則是 21 天）。

### 離開

使用 `/coi church leave`。領袖不能離開。領袖必須先用 `/coi church ownership handoff <player> confirm` 把教會交給別人，或者用 `/coi church disband` 解散它（之後你有 45 秒，在聊天欄裡準確輸入教會名字來確認）。

## 怎樣祈禱？

祈禱讓教會的加成保持生效。成員 **14 天**沒有祈禱，或者 14 天沒有登入，就不再計入教會。

你可以這樣祈禱：

- `/coi church pray`
- 教會選單裡的祈禱按鈕
- 在聊天欄裡逐行誦唸教會任意一位成員的完整[尊名](/zh-tw/magic/honorific-names/)（這算作外部祈禱）

| 祈禱規則 | 數值 |
|---|---|
| 全額生效範圍 | 活躍教會地點 **100 格**以內 |
| 遠離教會地點時 | 按 **10%** 的強度計算 |
| 祈禱連線持續 | **30 分鐘** |
| 祈禱效果冷卻 | **12 小時** |

祈禱訊息會準確地告訴你得到了什麼。如果你覺得增益很弱，首先要做的就是讓成員在教會地點附近祈禱。

## 教會的各個身份有什麼作用？

| 身份 | 作用 |
|---|---|
| **領袖** | 擁有教會並設定它的途徑。放置核心，管理成員、地點和天使。不算作自己教會的錨點 |
| **副領袖** | 對大多數教會系統擁有和領袖相近的權限。最多 **2** 名。可以管理區域總部。不算作成員錨點 |
| **天使** | 需要**序列3**或更強。擁有強力的祝福、恩惠和金庫權限。名額為 **3** 個，每個活躍的分部再加 1 個。如果天使人數超過名額，天使的效果會暫停 |
| **首席執事** | 負責一個教會地點，並保證它有人照看 |
| **主教** | 協助一個地點。每個地點最多 **2** 名 |
| **區域經理** | 負責一個區域總部 |
| **信徒** | 祈禱並提供錨點權重。3 天后成為初級信徒，7 天后成為信徒，14 天后成為資深信徒 |

地點相關的身份見[教會管理](/zh-tw/magic/church-management/)。

## 教會聊天

用 `/coi church chat <message>` 和整個教會說話，或者在普通聊天訊息前加上 `!c`、`!cc` 或 `!church`，例如 `!c meet at the cathedral`。

## 瘋狂底線減輕

從序列4開始，每個非凡者都有一條神性瘋狂底線，也就是恢復手段無法消除的那部分瘋狂值。一個健康的教會會為成員降低這條底線，對領袖和副領袖的效果最強。例如，一位新神在信眾增長起來之前，底線大約在 30%。

各條底線、減輕公式和各身份的上限，見[教會增益與錨點](/zh-tw/magic/church-perks/#瘋狂底線減輕)。瘋狂值的一般說明見[瘋狂與異變](/zh-tw/magic/mutation/)。

<Notice tone="info" title="獵人途徑的部眾">
獵人途徑的[指揮鏈部眾](/zh-tw/magic/sequence-zero/#獵人途徑的部眾可以代替教會)會給沒有活躍教會的成員提供它自己的底線減輕。那不是教會身份。
</Notice>

## 教會與神

在通往[序列0](/zh-tw/magic/sequence-zero/)的路上，教會非常重要。宣告者需要自己的教會承載 **20** 個錨點，而且必須是教會的領袖、副領袖或天使。參加 **10** 次教會禮拜也是傳奇事蹟之一。

一旦有神坐上神座，教會成員身份本身不會帶來任何屬性加成。它只是讓神能用**諭令**找到你。每位成員都有一個虔誠開關。關閉是立刻生效的，但重新開啟要等一週。

## 在哪裡找到教會選單？

- `/coi church menu`，或者點選你的教會核心
- 角色選單 `/coi menu character` 裡的教會欄位（一個信標）
- [COI 客戶端](/zh-tw/guides/client-mod/)裡的教會選單（預設按鍵 M）

## 成員指令

| 指令 | 作用 |
|---|---|
| `/coi church menu` | 開啟教會選單 |
| `/coi church accept` | 接受最近的邀請 |
| `/coi church leave` | 離開你的教會 |
| `/coi church pray` | 祈禱 |
| `/coi church chat <message>` | 教會聊天（或者 `!c <message>`） |
| `/coi church info` | 你教會的詳細資訊 |
| `/coi church members` | 成員列表 |
| `/coi church status` | 教會健康狀況一覽 |
| `/coi church perks` | 你當前的增益以及限制它們的因素 |
| `/coi church acting` | 你的教會扮演加成 |
| `/coi church pathway progress` | 對你自己途徑的支援 |
| `/coi church pathway <pathway> progress` | 對你教會中另一條途徑的支援 |
| `/coi church my-site` | 你被分配的教會地點 |
| `/coi church cooldowns` | 你的教會冷卻 |
| `/coi church top [pathway]` | 最強的教會，可以看總榜或某一條途徑 |
| `/coi church vault` | 開啟教會金庫 |
| `/coi church artifacts list` | 你的教會存放的封印物 |
| `/coi church artifact request <artifactId>` | 申請借用一件封印物 |
| `/coi church artifact return` | 歸還借用的封印物 |

領袖和管理者的指令見[教會管理](/zh-tw/magic/church-management/#領袖和管理者指令)。
