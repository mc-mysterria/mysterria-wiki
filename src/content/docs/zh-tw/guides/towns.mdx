**城鎮**是你和朋友們共享的受保護土地。城鎮之外的人都不能在那裡建造、破壞方塊或開啟箱子。

所有城鎮指令都以 `/lands`（或 `/land`）開頭。單獨輸入 `/lands` 會開啟城鎮選單，大部分事情在那裡也能做。

## 怎樣建立城鎮？

```
/lands create <name>
```

- 它要花 **32 科佩**，從你的[錢包](/zh-tw/guides/economy/)裡扣除。
- 它會免費圈下你周圍 3 乘 3 的區塊（你所在的區塊，加上每個方向各一個）。
- 名字需要 5 到 24 個拉丁字母或數字。可以有空格。
- 你只能擁有**一個**城鎮，也只能在一個城鎮裡被信任。

## 怎樣圈更多的地？

```
/lands claim       圈下你所在的區塊
/lands unclaim     取消圈定這個區塊
```

| 項目 | 花費 |
|---|---|
| 每個額外的區塊 | 10 科佩 |
| 取消圈定一個區塊 | 退還 15% |

- 新圈的地必須**和你現有的土地相連**。
- 你不能在其他城鎮周圍 **1 個區塊**以內圈地（如果那個城鎮屬於某個國家，則是 3 個區塊），除非那個城鎮允許你的身份在它的邊界圈地。
- 城鎮一開始可以圈 **100 個區塊**，每有一名受信任的成員**再加 5 個**。更高的[等級](#城鎮等級)會增加更多。
- 預設**只有城主**可以圈地。城主可以在身份設定裡把這個權限給其他身份。

玩家無法使用 `/claim` 和 `/unclaim` 這兩個簡寫指令。

## 基本城鎮指令

| 指令 | 作用 |
|---|---|
| `/lands` | 開啟城鎮選單 |
| `/lands trust <player>` | 邀請一位玩家。對方用 `/lands accept` 接受 |
| `/lands untrust <player>` | 移除一位玩家 |
| `/lands setrole <player> <role>` | 更改成員的身份 |
| `/lands ban <player>` | 禁止一位玩家進入你的土地 |
| `/lands deposit <amount>` | 把錢存進城鎮銀行 |
| `/lands withdraw <amount>` | 取錢（預設只有城主可以） |
| `/lands rename <name>` | 花 10,000 科佩給城鎮改名，每天最多一次 |
| `/lands setowner <player>` | 從城鎮銀行花 5,000 科佩，把城鎮交給別人 |
| `/lands upkeep`、`/lands taxes` | 檢視下一次維護費和稅款 |
| `/lands delete` | 解散你的城鎮 |

**進入和離開訊息**在城鎮選單裡用 **Enter Message** 物品設定。沒有 `/lands greeting` 或 `/lands farewell` 指令。

領地傳送（`/lands spawn`、`/lands wild`、傳送到某個區塊）貴得離譜，實際上等於關閉了。Mysterria 沒有 `/home` 或 `/tpa`。

想在城鎮聊天裡說話，就在訊息前面加上 `!l`、`!land` 或 `!lands`。

## 城鎮身份

每個身份決定了它的玩家在你的土地上能做什麼。城主可以在城鎮選單裡更改每個身份的權限。

| 身份 | 誰 | 預設權限 |
|---|---|---|
| **城主**（Owner） | 建立者 | 一切 |
| **管理員**（Admin） | 受信任的幹部 | 建造、破壞、使用容器和門、信任、取消信任、封禁和設定身份、編輯領地和身份設定。預設不能圈地、取錢或管理戰爭 |
| **成員**（Member） | 普通居民 | 建造、破壞、種地、使用容器、存錢 |
| **租戶**（Tenant） | 租用某片區域的玩家 | 在租用的區域裡建造和使用東西，並決定還有誰可以使用 |
| **國家**（Nation） | 同一國家的成員 | 使用門和機關、進入、撿起物品、在你的邊界圈地 |
| **盟友**（Ally） | 盟友城鎮的成員 | 和國家相同 |
| **未信任**（Untrusted） | 任何訪客 | 進入、撿起物品、攻擊怪物 |

預設情況下，城鎮裡對所有身份都**關閉了 PvP**。城主可以按身份開啟它，例如用於競技場。

如果你攻擊了另一名玩家，會被標記為戰鬥狀態 **20 秒**。在被標記時下線會讓你死亡。

## 經營城鎮要花多少錢？

### 維護費

- 每個城鎮每 **7 天**在 23:00 為**每個已圈區塊支付 3 科佩**。這筆錢從城鎮銀行扣除，進入伺服器銀行 *The Narrator*。
- 新城鎮在最初 **2 天**內不用付錢。
- 從付款前 2 天開始，如果銀行餘額不夠，有存錢權限的成員每小時都會收到提醒。
- 如果銀行付不起，你的區塊**不會**被移除。
- 更高的[等級](#城鎮等級)最多可以減少 40% 的維護費。

屬於某個國家的城鎮不向伺服器支付維護費，而是向國家交稅。見[國家與戰爭](/zh-tw/guides/nations-and-wars/)。

### 稅收

城主可以在每個付款週期向受信任的成員收稅，每塊區域最多 **10 科佩**。付不起的成員會被自動取消信任。

## 城鎮等級

城鎮滿足要求時會**自動**升級，不再滿足時（例如銀行餘額下降）會**降一級**。每個等級都需要 **5 名受信任的玩家**，以及**城鎮銀行**（`/lands deposit`）裡的一筆餘額。

<Figure src={landsLevel} alt="Lands 的等級選單，有兩把掛鎖，每把對應下一級的一項要求" caption="/lands 裡的等級選單。每把掛鎖代表下一級的一項要求。" contain />

| 等級 | 名稱 | 受信任的玩家 | 城鎮銀行 | 額外領地 | 額外成員名額 | 維護費 |
|---|---|---|---|---|---|---|
| 1 | **庇護所**（Shelter） | - | - | - | - | 全額 |
| 2 | **村落**（Hamlet） | 5 | 5,000 科佩 | +50 | +25 | -10% |
| 3 | **教區**（Parish） | 5 | 12,500 科佩 | +100 | +50 | -20% |
| 4 | **市鎮**（Borough） | 5 | 25,000 科佩 | +150 | +75 | -30% |
| 5 | **領邦**（Domain） | 5 | 40,000 科佩 | +200 | +100 | -40% |

**領邦是最高等級。**城鎮一開始有 26 個成員名額。

領邦可以建立[國家](/zh-tw/guides/nations-and-wars/)。

## 城鎮對其他系統的意義

- 你可以在城鎮領地裡藏起自己的[集市](/zh-tw/guides/agora/)入口。
- [教會](/zh-tw/magic/churches/)可以把它們的金庫和城鎮關聯起來。
- 擁有宏偉建築的大型城鎮可以獲得[城鎮增益](#城鎮增益)。

## 城鎮增益

**城鎮增益**是一種永久的區域效果，城鎮完成一項重大建築工程後，由管理團隊放置在城鎮上。你無法購買它，也無法用指令領取。

### 怎樣獲得城鎮增益？

1. 建造一座符合你想要的增益的宏偉建築，例如一座大教堂、一座大圖書館或一道城牆。
2. 在 Discord 上提交支援工單，附上座標和截圖。
3. 管理團隊會評估建築品質、城鎮的等級和人口。
4. 如果批准，管理團隊會把增益放在你城鎮的某片區域上。

### 有哪些增益？

| 增益 | 作用 | 城鎮等級 | 受信任的玩家 | 半神 |
|---|---|---|---|---|
| **農業**（Agriculture） | 作物生長快得多 | 村落（2） | 5 | - |
| **怪物防護**（Mob Protection） | 區域內不會生成敵對怪物 | 市鎮（4） | 12 | - |
| **藥水效果**（Potion Effects） | 持續的效果，例如迅捷、急迫或夜視 | 領邦（5） | 18 | - |
| **經驗加成**（Experience Boost） | 在區域內獲得更多經驗 | 領邦（5） | 22 | - |
| **盔甲修復**（Armor Repair） | 慢慢修復磨損的盔甲 | 領邦（5） | 30 | - |
| **扮演加成**（Acting Boost） | 站在區域內時扮演更快 | 領邦（5） | 40 | 3 |
| **靈性**（Spirituality） | 定時恢復靈性 | 領邦（5） | 45 | 5 |

- **受信任的玩家**是城鎮裡受信任的成員。**半神**是序列4或更強的受信任成員。
- 經驗加成、盔甲修復、扮演加成和靈性以前要求城鎮等級 6、8 和 10，這些等級已經不存在了。既然**領邦**現在是最高等級，這些增益就由玩家人數、半神人數和建築本身來決定。

### 增益有多強？

每個增益都由管理團隊針對它的城鎮來設定，所以數值各不相同。目前伺服器上生效的增益有：

- **扮演加成**在一個城鎮給站在區域內的玩家 +18% 的扮演速度，在另一個城鎮是 +45%。
- **靈性**在三個城鎮每 20 秒恢復 50 點靈性，在一個城鎮每 10 秒恢復 50 點，在另一個城鎮每 10 秒恢復 30 點。
- **怪物防護**覆蓋一個城鎮中心周圍半徑 100 格的範圍。

增益可以覆蓋一座紀念碑周圍的圓形區域、一座建築周圍的方形或其他形狀區域，或者城鎮的整個領地。

### 獲得批准的竅門

建築應該能讓人聯想到增益，就像龍的雕像適合怪物防護，大教堂適合靈性。小房子是不夠格的。想想那種能定義整片地貌的世界奇觀。管理團隊會裡裡外外都檢查，所以不要提交沒完工的建築或空殼子。
