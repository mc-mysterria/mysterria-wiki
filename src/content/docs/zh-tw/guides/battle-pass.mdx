**戰鬥通行證**會因為每日和每週任務給你點數，點數會提升你的等級。許多等級都帶有獎勵，例如金錢、能量碎片、商行點數、扮演之瓶、地牢鑰匙，或者兩條恩賜途徑之一。

用 `/battlepass` 或 `/bp` 開啟。

<Figure src={bpMain} alt="戰鬥通行證選單，有 Rewards、Premium、Quests 和 Info 按鈕" caption="戰鬥通行證選單。" contain />

## 戰鬥通行證怎樣運作？

1. 完成**每日任務**和**每週任務**來獲得戰鬥通行證點數。
2. 一個等級的點數攢滿後，你就進入下一級。
3. 到達獎勵等級時，在戰鬥通行證選單裡開啟 **Rewards**，**點選獎勵來領取**。獎勵不會自動發放。

每位玩家都有**免費通行證**。**高階通行證**會增加第二條獎勵線，以及額外的高階專屬任務。

## 任務

### 每日任務

- 你同一時間有 **9 個每日任務**，其中 4 個簡單、3 箇中等、2 個困難。
- 它們在每天**基輔時間 11:59** 重置。
- 每個任務值 **25 到 50 點**，例如馴服 3 只狼，或者達到 15 級經驗。

### 每週任務

- 每 **7 天**解鎖一週的新任務，時間是基輔時間週六 07:00。當前賽季從 2026 年 5 月 16 日開始，共 **26 周**。最後一週在 2026 年 11 月 7 日解鎖。
- 之前幾週的任務會一直開放，你不需要完成一週才能開始下一週。
- 大多數每週任務值 **95 點**。高階專屬的每週任務值 **112 點**。

## 我需要多少點數？

| 等級 | 每級點數 |
|---|---|
| 普通等級 1 到 75 | 150 |
| 獎勵等級 1 到 75 | 200 |
| 普通等級 76 到 100 | 150 |
| 獎勵等級 76 到 100 | 350 |

加起來，**到達第 75 級需要 11,750 點**，**到達通行證終點第 100 級需要 16,900 點**。第 76 到 100 級是額外等級。高階通行證的獎勵等級在不同的級數上，但數量一樣多，所以總數相同。

## 這些獎勵有什麼用？

| 獎勵 | 說明 |
|---|---|
| 科佩 | [金錢](/zh-tw/guides/economy/)，加到你的 `/wallet` 裡 |
| 能量碎片 | 用於秘密組織和野生非凡者的[物品貨幣](/zh-tw/guides/economy/#能量碎片) |
| 商行點數 | 在[璀璨商行](/zh-tw/guides/emporium/)裡使用 |
| 扮演之瓶 | 扔出去，為你當前的序列獲得[扮演](/zh-tw/magic/acting/)點數 |
| 衰敗君王恩賜途徑、原初飢餓恩賜途徑 | 一枚恩賜信物，解鎖對應[恩賜途徑](/zh-tw/magic/boons/)的序列9。你透過獻祭非凡物品來提升它 |
| 配方紙 | 收集 3 或 4 張，組成一份完整的配方 |
| 配方代幣 | 兌換序列4以內的任意配方 |
| 材料代幣 | 兌換任意一種已知的材料 |
| 簡易鑰匙 | 一次單人重新進入[地牢](/zh-tw/guides/dungeons/)的機會 |
| 高階鑰匙 | 一次整隊重新進入地牢的機會 |
| 首領指南針 | 指向最近的[世界首領](/zh-tw/guides/bosses/)，使用後消耗 |
| 通用外觀代幣 | 給武器或工具換上自訂皮膚 |
| 聊天顏色禮包 | 365 天內在所有聊天頻道使用顏色和格式 |

## 怎樣獲得高階通行證？

**Premium BattlePass** 在[伺服器商店](https://www.mysterria.net/en/store)出售。它會解鎖上面的高階獎勵線和高階專屬的每週任務。
