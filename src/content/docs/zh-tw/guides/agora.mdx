**集市**（Agora）是藏在隱秘門後的地下市場，玩家在這裡匿名地互相買賣。商品上不寫名字，所以買家和賣家永遠不知道對方是誰。

集市**沒有任何指令**。你從一扇門走進去，然後右鍵點選在那裡工作的人。

## 怎樣進入集市？

### 使用公共入口

伺服器在**座標 (0, 0)** 設有一個**公共入口**。任何人都可以使用。右鍵點選門就能下去。

### 製作你自己的秘密入口

```
O E O        O = 黑曜石
E D E        E = 迴響碎片
O E O        D = 深色橡木門
```

<Figure src={doorCraft} alt="黑曜石和迴響碎片圍著一扇深色橡木門擺在合成格裡" caption="秘密入口的配方。" contain />

手持**秘密入口**右鍵點選一個方塊，就能把它變成一扇緋紅之門。只有滿足下面的條件才有效：

- 這個位置上方有**兩格空間**
- 它在某個[城鎮](/zh-tw/guides/towns/)的**已圈領地**內，並且你在那裡是**受信任**的
- 這塊領地裡還沒有藏著一扇門，因為每塊領地只允許**一個入口**

右鍵點選門就能下去。

### 它是秘密，不是鎖

任何找到你這扇門的人都能走進去。把它藏好。

這扇門無法被破壞、炸燬或移動。唯一能去掉它的辦法，是取消圈定它所在的領地。門每 30 分鐘檢查一次，如果連續第三次檢查都發現它的領地沒有被圈定，門就會被移除。只有當有玩家載入了那片區域時才會檢查。所以只要附近有人，不再被圈定的領地上的入口大約一個半小時內就會消失。想要搬遷入口，就取消圈定那個區塊，之後再重新圈定，然後放一個新制作的入口。舊的門永遠不會回來。

### 怎樣出來

右鍵點選**出口門**。你會在當初下去的地方回到地面。如果那個入口已經不在或者不安全，你會回到世界出生點。

## 裡面有什麼規則？

- **沒有人會受傷。**沒有 PvP，沒有怪物，沒有摔落傷害，沒有爆炸，也沒有火。
- **不能使用非凡能力。**它們在集市裡無效。
- **沒有捷徑。**末影珍珠、紫頌果、鞘翅和載具都被禁止。你只能從出口門離開。
- **你的物品欄歸你自己。**進出門時都不會拿走任何東西。
- **不能建造**，也不能開啟容器，除非是在你租下的[攤位](#攤位)裡。

## 集市裡有誰在工作？

右鍵點選任何人就能和他們交談。

| 誰 | 做什麼 |
|---|---|
| **銷贓人**（The Fence） | 把你的貨物掛出去賣 |
| **集市店員**（Bazaar Clerk） | 瀏覽和購買 |
| **線人**（The Informant） | 按途徑和序列搜尋 |
| **帳房**（Ledger Keeper） | 領取你買的東西和你的錢 |
| **信使驛站**（Courier Post） | 把買的東西送到你手上 |
| **攤位管理員**（Plot Warden） | 租用攤位 |
| **攤主**（Stall Keeper） | 租戶自己的店面 |
| **軍需官**（Quartermaster） | 建築方塊（以前的 `/shop`） |

<Figure src={fence} alt="銷贓人在集市的櫃檯後等著" caption="銷贓人收下你的貨物並掛出出售。" />

## 價格怎麼寫？

價格使用伺服器的[三種貨幣](/zh-tw/guides/economy/)。64 科佩等於 1 里克，64 里克（4,096 科佩）等於 1 因蒂費爾。

價格會以最簡短的組合來顯示，例如顯示 `16 coppets 11 licks`，而不是 720 科佩。需要你自己輸入價格的地方，用 `c` 表示科佩，`l` 表示里克，`v` 表示因蒂費爾。

## 怎樣在集市裡賣東西？

把物品交給**銷贓人**並說出價格。他會先建議一個價格，非凡材料按序列估價，普通物品按類似東西的成交價估價。你可以不理會這個建議，隨便定價。

| 規則 | 數值 |
|---|---|
| 掛單費 | 你定價的 **2%**（至少 1 科佩） |
| 交易稅 | 成交額的 **8%** |
| 價格範圍 | 1 到 1,000,000 科佩 |
| 每天新掛單 | **3** 個 |
| 同時在售的掛單 | **10** 個 |
| 掛單持續 | **72 小時** |

掛單費是**預先**支付的，無論物品賣掉、過期還是被取消，都不會退還。

### 什麼東西不能賣？

- 潛影盒、收納袋以及其他能裝物品的東西
- 基岩
- 和你綁定的物品
- 歷史契約的控制物品

### 東西賣出去時

你只會收到一條訊息，說*有一枚錢幣以你的名義被存了起來*，不會說賣了什麼、賣了多少錢。到**帳房**那裡領取錢款。你離線時成交的交易也會等著你。

### 沒賣出去時

72 小時後，沒賣出去的掛單會過期，物品會進入你在帳房那裡的**儲藏**。提前取消掛單，物品也會去同一個地方。

## 怎樣在集市裡買東西？

**集市店員**展示所有在售的商品。如果你知道自己想要什麼，可以找**線人**按途徑和序列搜尋。

你只需支付標籤上的價格，不用多付。稅從賣家那一份裡扣。你不能買自己的掛單。

買到的東西**不會進入你的物品欄**。它們會在帳房那裡等著，除非你在[信使驛站](#信使驛站)留了一個號角。

## 從帳房領取

市場欠你的所有東西都會留在**帳房**那裡，直到你來領取。它們永遠不會過期。

- **你的儲藏**裡有你買的物品、過期或被取消的掛單，以及從你失去的攤位裡搶救出來的東西。你的物品欄有多少空間就拿多少，剩下的會繼續留著。
- **你的帳本**裡有每筆交易扣稅後的錢款。領取時會一次性付清所有欠款。

## 信使驛站

在**信使驛站**留下一個**召喚號角**，你**買**的所有東西都會由你的[信使](/zh-tw/guides/couriers/)送到你手上，無論你在哪裡。

- 一次只能留一個號角。你隨時都可以把它拿回來，之後就不再寄送。
- 寄送是免費的。號角就是代價。
- 你賣東西的錢不會被寄送。要到帳房那裡領取。

## 攤位

**攤位**是市場裡一個可以租用、建造和出售東西的房間。找**攤位管理員**租一個。

<Figure src={plots} alt="集市的攤位區，燈籠照亮了四周" caption="攤位區。" />

| 規則 | 數值 |
|---|---|
| 租金 | **1 因蒂費爾**（4,096 科佩） |
| 租期 | **7 天** |
| 每位玩家的攤位 | **1** 個 |
| 寬限期 | **48 小時** |

付了租金之後，你可以在**你的攤位裡**建造、破壞方塊和使用箱子。你的店面會出現一位**攤主**。點選它的訪客能看到你賣什麼，你也會有自己的櫃檯。

### 保住你的攤位

在一週結束前再付一次錢給攤位管理員，就能續租一週。如果錯過了，你會有 **48 小時的寬限期**，期間會收到提醒，所有東西都還在。

### 失去你的攤位

寬限期過後你會被收回攤位，但**任何東西都不會被銷燬**。你箱子、物品展示框和盔甲架裡的所有東西，以及留在地上的任何東西，都會進入你在帳房那裡的儲藏。房間會被重置，留給下一位租戶。

你也可以在攤位管理員的選單裡提前退租。

## 攤位櫃檯

**櫃檯**是攤位裡箱子上的一塊告示牌，它會賣東西給任何路過的人，沒有掛單費，也不用等待。每個攤位最多可以有 **12 個**。

1. 放一個箱子，再在上面放一塊告示牌（貼在正面或放在頂上）。
2. 在**第 1 行**寫 `[Market]`。
3. 在**第 2 行**寫價格，可以直接寫科佩的數字，也可以用簡寫，例如 `3v 12l 5c`（3 因蒂費爾、12 里克和 5 科佩，也就是 13,061 科佩）。
4. 也可以在**第 3 行**寫每次購買的數量，從 1 到 64。不寫就是 1。
5. **手持你想賣的物品，右鍵點選告示牌。**

告示牌會重新顯示為 **STALL COUNTER**，上面寫著物品、價格和你的名字。

| 操作 | 結果 |
|---|---|
| 手持物品右鍵點選 | 設定或更改它賣的東西 |
| 空手右鍵點選 | 檢視庫存和總銷量 |
| 潛行 + 右鍵點選 | 關閉櫃檯 |

**箱子就是你的庫存。**補貨就往裡面多放東西。箱子空了，櫃檯就賣完了。想改價格，就破壞告示牌重新設定。

從櫃檯購買時，先右鍵點選告示牌一次檢視價格，然後**在 6 秒內再點一次**付款。物品會直接到你手裡。

告示牌、箱子或攤位任何一個沒了，櫃檯就會關閉。

## 要花多少錢？

| 項目 | 花費 |
|---|---|
| 秘密入口 | 黑曜石、迴響碎片和一扇深色橡木門 |
| 掛單一件物品 | 你定價的 2%（至少 1 科佩） |
| 賣出一件物品 | 成交額的 8% |
| 買一件物品 | 標籤上的價格 |
| 租一個攤位 | 每週 1 因蒂費爾（4,096 科佩） |
| 信使寄送 | 免費（號角就是代價） |
