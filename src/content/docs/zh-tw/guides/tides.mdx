每日潮汐是持續一天的全服加成。所有玩家同一時間只有一種潮汐生效，它們按固定的每週輪換進行，你可以提前做好安排。

## 潮汐什麼時候變化？

一個潮汐日從**基輔時間 00:00 到 24:00**（Europe/Kyiv，冬季是 UTC+2，夏季是 UTC+3）。到了基輔時間午夜，無論你住在哪裡，下一種潮汐都會對所有人開始。

## 七種潮汐是什麼？

| 潮汐 | 作用 | 倍率 |
|---|---|---|
| **勤勉之潮**（Tide of Diligence） | 每次獲得的扮演都翻倍 | 獲得的扮演 x2 |
| **狩獵之潮**（Hunting Tide） | 生物生成和掉落更多，稀有材料更是多得多 | 生物生成 x2，生物掉落 x2，稀有材料 x3 |
| **幸運之潮**（Tide of Fortune） | 箱子更豐厚，保底更快 | 箱子戰利品 x2.5，保底只需一半的開箱次數，稀有戰利品 x2.5 |
| **狂野之潮**（Wild Tide） | 更多[野生非凡者](/zh-tw/magic/wild-beyonders/) | 野生非凡者生成 x2，野生非凡者上限 x2 |
| **耐心之潮**（Tide of Patience） | 扮演冷卻減半 | 扮演冷卻 x0.5 |
| **深潮**（Deep Tide） | 更多可採集節點，箱子裡的材料也更多 | 可採集節點 x2，箱子裡的材料 x2，稀有材料 x2 |
| **緋紅之潮**（Crimson Tide） | [緋紅之月](/zh-tw/magic/crimson-moon/)的機率提高到五倍 | 緋紅之月機率 x5，生物掉落 x1.5 |

“稀有”指的是**序列3或更強**，也就是序列3、2和1。在狩獵之潮和深潮時，稀有材料加成適用於生物掉落和箱子裡找到的材料，但不適用於可採集節點。

在緋紅之潮時，每個夜晚出現緋紅之月的機率是 **50%**，而不是平時的 10%。主世界的每個夜晚單獨判定，所以玩上一整天，你很可能至少會遇到一次。

### 星期幾是哪種潮汐？

輪換按照上表的順序進行，所以每種潮汐每週都落在同一天：

| 日期（基輔時間） | 潮汐 |
|---|---|
| 星期一 | 狩獵之潮 |
| 星期二 | 幸運之潮 |
| 星期三 | 狂野之潮 |
| 星期四 | 耐心之潮 |
| 星期五 | 深潮 |
| 星期六 | 緋紅之潮 |
| 星期日 | 勤勉之潮 |

管理團隊可以更改輪換，或者把某一天固定成另一種潮汐，所以要確認的話，請在遊戲裡檢視 `/coi tide calendar`。

### 加成疊加時有上限嗎？

有。當好幾種加成同時生效時，例如潮汐加上緋紅之月，再加上藥師途徑的月亮權柄，總數是有上限的。

- 生物生成上限是 **x4**。
- 獲得的扮演上限是 **x2.5**。

在勤勉之潮時，某個扮演來源達到上限後，多出來的部分會儲存成溢出扮演，而不是填進你的扮演條。溢出扮演只在序列3及更強時存在，詳見[篡位](/zh-tw/magic/usurpation/)。

## 哪種潮汐對我幫助最大？

- **前期和中期序列。**你的瓶頸是扮演條，所以**勤勉之潮**幫助最大。**狂野之潮**也有幫助，因為野生非凡者只存在於序列9到5。
- **序列3及更強。**比起扮演條，每個扮演法的冷卻更拖你後腿，所以**耐心之潮**是屬於你的日子。狩獵之潮、幸運之潮和深潮也帶有針對你的稀有級加成。
- **搜刮。**開箱子留到**幸運之潮**，找材料留到**狩獵之潮**或**深潮**。

生物掉落加成對徽章生物和稀有材料最重要。自訂的[非凡生物](/zh-tw/magic/creatures/)本來幾乎每次都會掉落它們的常見材料。

:::tip[幸運之潮與保底]
只有在你開啟容器時才會檢查保底。如果幸運之潮時你離保底閾值很近，就在午夜前再開一個箱子。無論如何你的計數都會保留，但閾值減半的效果會隨著這一天結束。
:::

## 怎樣知道今天是哪種潮汐？

- **登入卡片。**進入伺服器幾秒後，聊天欄裡的一張卡片會顯示潮汐、它的作用和剩餘時間。
- **客戶端彈窗。**如果你用 [COI 客戶端](/zh-tw/guides/client-mod/)，同樣的卡片會以彈窗形式出現。
- **每小時提醒。**每小時在聊天欄裡顯示一行，如果你剛進入伺服器或者在掛機就會跳過。
- **Boss 血條。**到這一天結束的倒計時。
- **潮汐切換。**潮汐變化時，所有線上的人都會看到一個標題並聽到一個音效。

## 有哪些指令？

| 指令 | 作用 |
|---|---|
| `/coi tide` 或 `/coi tide status` | 今天的潮汐、它的倍率和剩餘時間 |
| `/coi tide calendar [days]` | 從今天開始接下來的潮汐（預設 14 天，最多 60 天） |
| `/coi tide notify` | 關閉或開啟你的每小時提醒 |
| `/coi tide bar` | 關閉或開啟你的潮汐 Boss 血條 |

## 潮汐永遠不會改變什麼？

| 系統 | 為什麼不受影響 |
|---|---|
| [獨一性](/zh-tw/magic/uniqueness/)評分 | 它按 31 天來衡量，所以你恰好在哪幾天玩不應該有影響 |
| [篡位](/zh-tw/magic/usurpation/)的戰爭點數 | 點數按潮汐加成之前的數值計算 |
| 試煉 | 試煉可能讓你失去物品欄，所以日曆不應該改變機率 |
| 戰鬥傷害 | 平衡每天都保持一致 |
