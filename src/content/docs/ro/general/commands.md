Acestea sunt comenzile pe care le pot folosi jucătorii obișnuiți pe serverul principal. Aproape tot pe Mysterria merge prin meniuri, așa că o comandă care lipsește de aici probabil nu funcționează pentru jucători.

## Comenzi care nu există

**Nu există** `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` sau `/back`. Vezi [Lume și siguranță](/ro/general/world-and-safety/#există-home-spawn-sau-tpa).

## Primii pași

| Comandă | Ce face |
|---|---|
| `/register <password> <password>` | Înregistrează un cont offline (doar la prima vizită) |
| `/login <password>` | Te autentifică într-un cont offline |
| `/verify` | Îți leagă contul cu codul din [profilul de pe site](https://www.mysterria.net/en/profile) |
| `/magic` | Ghidul pentru începători, cu meniul **Loot Focus** |
| `/guide` | Cartea-ghid din joc |
| `/faq` | Întrebări frecvente |
| `/hints` | Sfaturi de joc |
| `/lang` | Schimbă limba mesajelor pluginului |

## Beyonderul tău

| Comandă | Ce face |
|---|---|
| `/coi menu character` | Ecranul personajului: Secvența, Interpretarea, Viața, Spiritualitatea, Nebunia |
| `/coi menu abilities` | Abilitățile tale |
| `/coi menu native` | Comută între ecranele [Modului Client](/ro/guides/client-mod/) și meniurile tip cufăr |
| `/coi acting` | Timpii de așteptare ai metodelor de Interpretare și Interpretarea ta pe surse. Vezi [Interpretare](/ro/magic/acting/) |
| `/bounty` (sau `/coi bounty`) | Recompense pentru Interpretare |
| `/ritual status` | Scorul tău de ritual pentru următoarea Secvență. Vezi [Ritualuri](/ro/magic/rituals/) |
| `/ritual view <sequence>` | Sarcinile tale de ritual într-un meniu, unde poți cere o reextragere |
| `/coi practice` | Exersează minijocul de preparare fără să riști nimic |
| `/coi tide` | Mareea Zilnică de azi. `/coi tide calendar` arată zilele care urmează. Vezi [Mareele zilnice](/ro/guides/tides/) |

Jucătorii de Secvențe înalte mai folosesc `/coi usurp` ([Uzurpare](/ro/magic/usurpation/)), `/coi ascend` și `/coi ascension` ([Secvența 0](/ro/magic/sequence-zero/)) și `/coi church` ([Biserici](/ro/magic/churches/)).

## Bani și magazine

| Comandă | Ce face |
|---|---|
| `/wallet` | Banii tăi. Vezi [Economie](/ro/guides/economy/) |
| `/emporium` | [Brilliant Emporium](/ro/guides/emporium/) |
| `/daily` | Recompense zilnice |
| `/vote` | Votează pentru server |
| `/battlepass` (sau `/bp`) | Battle Pass |
| `/calendar` | Calendarul de recompense |
| `/tradeall` | Vinde toate ingredientele unui sătean pentru [Fragmente de Energie](/ro/guides/economy/#fragmente-de-energie) |
| `/oga` | Evenimentul Ancorele Zeilor Exteriori și magazinul lui de recompense (`/oga rewards`) |

## Orașe, grupuri și chat

| Comandă | Ce face |
|---|---|
| `/lands` (sau `/land`) | Creează și administrează un oraș. Vezi [Orașe](/ro/guides/towns/) |
| `/nations` (sau `/nation`) | Națiuni |
| `/wars` | Războaie între orașe |
| `/o` | [Ordine Secrete](/ro/guides/orders/). `/oc` este chatul Ordinului |
| `/party` | Grupul tău |
| `/msg <player> <message>` | Mesaj privat (și `/pm`, `/w`) |
| `/r` (sau `/reply`) | Răspunde la ultimul mesaj privat |
| `/ignore <player>` | Nu mai vezi mesajele unui jucător |
| `/titles` | Alege un titlu |
| `/chatcolor` | Culoarea din chat |

## Temnițe și evenimente

| Comandă | Ce face |
|---|---|
| `/subspace` | Fiecare temniță, intrarea ei și timpii tăi de așteptare. Vezi [Temnițe](/ro/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Grupul de temniță, verificarea că toți sunt gata, ieșirea din temniță |
| `/cosmos` | [Incursiunile Cosmosului](/ro/guides/cosmos-incursions/), cu `/cosmos guide`, `status`, `shop`, `balance` și `leaderboard` |
| `/pvpevent join` | Intră într-un eveniment Duels sau FFA cât timp înscrierile sunt deschise (`/pvpevent status` îți arată) |
| `/bedwars` | Bedwars |

## Altele

| Comandă | Ce face |
|---|---|
| `/sit`, `/lay` | Stai jos sau întinde-te |
| `/uar` | Timpul până la următoarea repornire a serverului |
