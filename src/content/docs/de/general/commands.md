Das sind die Befehle, die gewöhnliche Spieler auf dem Hauptserver nutzen können. Das meiste auf Mysterria läuft über Menüs. Ein Befehl, der hier fehlt, funktioniert für Spieler also wahrscheinlich nicht.

## Befehle, die es nicht gibt

Es gibt **kein** `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` oder `/back`. Siehe [Welt und Sicherheit](/de/general/world-and-safety/#gibt-es-home-spawn-oder-tpa).

## Erste Schritte

| Befehl | Was er tut |
|---|---|
| `/register <password> <password>` | Ein Offline-Konto registrieren (nur beim ersten Besuch) |
| `/login <password>` | Bei einem Offline-Konto anmelden |
| `/verify` | Dein Konto mit dem Code aus deinem [Profil auf der Website](https://www.mysterria.net/en/profile) verknüpfen |
| `/magic` | Neulingsleitfaden mit dem Menü **Loot Focus** |
| `/guide` | Leitfaden-Buch im Spiel |
| `/faq` | Häufige Fragen |
| `/hints` | Tipps zum Spiel |
| `/lang` | Die Sprache der Plugin-Nachrichten ändern |

## Dein Beyonder

| Befehl | Was er tut |
|---|---|
| `/coi menu character` | Dein Charakterbildschirm mit Sequenz, Schauspielen, Gesundheit, Spiritualität und Wahnsinn |
| `/coi menu abilities` | Deine Fähigkeiten |
| `/coi menu native` | Zwischen den Bildschirmen der [Client-Mod](/de/guides/client-mod/) und den Truhenmenüs wechseln |
| `/coi acting` | Abklingzeiten der Schauspielmethoden und dein Schauspielen nach Quelle. Siehe [Schauspielen](/de/magic/acting/) |
| `/bounty` (oder `/coi bounty`) | Schauspiel-Kopfgelder |
| `/ritual status` | Deine Ritualpunkte für die nächste Sequenz. Siehe [Rituale](/de/magic/rituals/) |
| `/ritual view <sequence>` | Deine Ritualaufgaben in einem Menü, in dem du um Neuwürfeln bitten kannst |
| `/coi practice` | Das Brau-Minispiel üben, ohne dass etwas auf dem Spiel steht |
| `/coi tide` | Die heutige Tägliche Tide. `/coi tide calendar` zeigt die kommenden Tage. Siehe [Tägliche Tiden](/de/guides/tides/) |

Spieler hoher Sequenzen nutzen außerdem `/coi usurp` ([Usurpation](/de/magic/usurpation/)), `/coi ascend` und `/coi ascension` ([Sequenz 0](/de/magic/sequence-zero/)) sowie `/coi church` ([Kirchen](/de/magic/churches/)).

## Geld und Shops

| Befehl | Was er tut |
|---|---|
| `/wallet` | Dein Geld. Siehe [Wirtschaft](/de/guides/economy/) |
| `/emporium` | Das [Brilliant Emporium](/de/guides/emporium/) |
| `/daily` | Tägliche Belohnungen |
| `/vote` | Für den Server abstimmen |
| `/battlepass` (oder `/bp`) | Der Battle Pass |
| `/calendar` | Der Belohnungskalender |
| `/tradeall` | Alle deine Zutaten an einen Dorfbewohner für [Energiescherben](/de/guides/economy/#energiescherben) verkaufen |
| `/oga` | Das Event Outer Gods Anchors und sein Belohnungsshop (`/oga rewards`) |

## Städte, Gruppen und Chat

| Befehl | Was er tut |
|---|---|
| `/lands` (oder `/land`) | Eine Stadt gründen und verwalten. Siehe [Städte](/de/guides/towns/) |
| `/nations` (oder `/nation`) | Nationen |
| `/wars` | Stadtkriege |
| `/o` | [Geheime Orden](/de/guides/orders/). `/oc` ist der Chat des Ordens |
| `/party` | Deine Gruppe |
| `/msg <player> <message>` | Private Nachricht (auch `/pm`, `/w`) |
| `/r` (oder `/reply`) | Auf die letzte private Nachricht antworten |
| `/ignore <player>` | Die Nachrichten eines Spielers nicht mehr sehen |
| `/titles` | Einen Titel wählen |
| `/chatcolor` | Chatfarbe |

## Dungeons und Events

| Befehl | Was er tut |
|---|---|
| `/subspace` | Jeder Dungeon, sein Eingang und deine Abklingzeiten. Siehe [Dungeons](/de/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Dungeon-Gruppe, Bereitschaftsprüfung, Dungeon verlassen |
| `/cosmos` | [Cosmos Incursions](/de/guides/cosmos-incursions/), mit `/cosmos guide`, `status`, `shop`, `balance` und `leaderboard` |
| `/pvpevent join` | Einem Event mit Duellen oder FFA beitreten, solange die Anmeldung offen ist (`/pvpevent status` zeigt das) |
| `/bedwars` | Bedwars |

## Sonstiges

| Befehl | Was er tut |
|---|---|
| `/sit`, `/lay` | Hinsetzen oder hinlegen |
| `/uar` | Zeit bis zum nächsten Neustart des Servers |
