Estos son los comandos que pueden usar los jugadores normales en el servidor principal. Casi todo en Mysterria funciona con menús, así que si un comando no está en esta lista, lo más probable es que no funcione para jugadores.

## Comandos que no existen

**No** existen `/home`, `/sethome`, `/spawn`, `/tpa`, `/rtp` ni `/back`. Mira [Mundo y seguridad](/es/general/world-and-safety/#hay-home-spawn-o-tpa).

## Primeros pasos

| Comando | Qué hace |
|---|---|
| `/register <contraseña> <contraseña>` | Registra una cuenta offline (solo la primera vez) |
| `/login <contraseña>` | Inicia sesión con una cuenta offline |
| `/verify` | Vincula tu cuenta con el código de tu [perfil de la web](https://www.mysterria.net/en/profile) |
| `/magic` | Guía para novatos, con el menú **Loot Focus** |
| `/guide` | Libro guía del juego |
| `/faq` | Preguntas frecuentes |
| `/hints` | Consejos de juego |
| `/lang` | Cambia el idioma de los mensajes del plugin |

## Tu Trascendente

| Comando | Qué hace |
|---|---|
| `/coi menu character` | Tu pantalla de personaje con Secuencia, Actuación, Salud, Espiritualidad y Locura |
| `/coi menu abilities` | Tus habilidades |
| `/coi menu native` | Cambia entre las pantallas del [Client Mod](/es/guides/client-mod/) y los menús de cofre |
| `/coi acting` | Tiempos de espera de cada método de Actuación y tu Actuación por fuente. Mira [Actuación](/es/magic/acting/) |
| `/bounty` (o `/coi bounty`) | Recompensas de Actuación |
| `/ritual status` | Tu puntuación de ritual para la siguiente Secuencia. Mira [Rituales](/es/magic/rituals/) |
| `/ritual view <secuencia>` | Tus tareas de ritual en un menú, donde puedes pedir que se cambien |
| `/coi practice` | Practica el minijuego de preparación sin arriesgar nada |
| `/coi tide` | La Marea diaria de hoy. `/coi tide calendar` muestra los próximos días. Mira [Mareas diarias](/es/guides/tides/) |

Los jugadores de Secuencias altas también usan `/coi usurp` ([Usurpación](/es/magic/usurpation/)), `/coi ascend` y `/coi ascension` ([Secuencia 0](/es/magic/sequence-zero/)) y `/coi church` ([Iglesias](/es/magic/churches/)).

## Dinero y tiendas

| Comando | Qué hace |
|---|---|
| `/wallet` | Tu dinero. Mira [Economía](/es/guides/economy/) |
| `/emporium` | El [Emporio Brillante](/es/guides/emporium/) |
| `/daily` | Recompensas diarias |
| `/vote` | Vota por el servidor |
| `/battlepass` (o `/bp`) | El Pase de batalla |
| `/calendar` | El calendario de recompensas |
| `/tradeall` | Vende todos tus ingredientes a un aldeano por [Fragmentos de Energía](/es/guides/economy/#fragmentos-de-energía) |
| `/oga` | El evento Outer Gods Anchors y su tienda de recompensas (`/oga rewards`) |

## Ciudades, grupos y chat

| Comando | Qué hace |
|---|---|
| `/lands` (o `/land`) | Crea y gestiona una ciudad. Mira [Ciudades](/es/guides/towns/) |
| `/nations` (o `/nation`) | Naciones |
| `/wars` | Guerras entre ciudades |
| `/o` | [Órdenes Secretas](/es/guides/orders/). `/oc` es el chat de la Orden |
| `/party` | Tu grupo |
| `/msg <jugador> <mensaje>` | Mensaje privado (también `/pm`, `/w`) |
| `/r` (o `/reply`) | Responde al último mensaje privado |
| `/ignore <jugador>` | Deja de ver los mensajes de un jugador |
| `/titles` | Elige un título |
| `/chatcolor` | Color del chat |

## Mazmorras y eventos

| Comando | Qué hace |
|---|---|
| `/subspace` | Todas las mazmorras, sus entradas y tus tiempos de espera. Mira [Mazmorras](/es/guides/dungeons/) |
| `/dparty`, `/ready`, `/leave` | Grupo de mazmorra, confirmar que estás listo y salir de la mazmorra |
| `/cosmos` | [Incursiones del Cosmos](/es/guides/cosmos-incursions/), con `/cosmos guide`, `status`, `shop`, `balance` y `leaderboard` |
| `/pvpevent join` | Únete a un evento de Duelos o FFA mientras las inscripciones están abiertas (`/pvpevent status` lo muestra) |
| `/bedwars` | Bedwars |

## Otros

| Comando | Qué hace |
|---|---|
| `/sit`, `/lay` | Sentarte o tumbarte |
| `/uar` | Tiempo que falta para el próximo reinicio del servidor |
